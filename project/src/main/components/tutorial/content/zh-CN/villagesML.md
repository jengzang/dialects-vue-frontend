# 村名机器学习

使用机器学习方法分析自然村名的模式和规律。

## 功能模块

- **村名搜寻**：按关键词、区域搜寻村名，查看详细信息与深度分析报告
- **字频分析**：分析村名中字符的使用频率、区域倾向性、语义嵌入向量与统计显著性
- **语义分析**：探索村名的语义类别、标签组合模式、语义网络关系与语义组成结构
- **空间分析**：可视化村名的地理分布、识别空间热点聚类、分析空间整合模式
- **模式分析**：提取N-gram模式、分析结构规律、发现村名命名的语言学特征
- **区域分析**：计算区域聚合统计、生成区域特征向量、进行跨区域比较分析
- **ML计算**：执行机器学习聚类分析、提取高维特征向量、进行子集深度分析（需登录）
- **系统信息**：查看数据库概览、表统计信息、系统运行状态与缓存管理

## 使用方式

1. 在导航中选择功能模块
2. 根据需要切换子标签页
3. 查看分析结果和可视化图表

## 提示

- 此功能为独立单页应用（SPA），通过 `/villagesML` 路由加载
- 目前覆盖广东自然村数据，后续可能扩展至全国
