# 村名机器学习

使用机器学习方法分析自然村名的模式和规律。

## 功能模块

- **搜索**（module=search）：搜索和浏览村名数据
- **字频分析**（module=character）：分析村名中汉字的出现频率、嵌入（embeddings）、网络关系（network）、显著性（significance）
- **语义分析**（module=semantic）：按语义类别分析村名的分类规律

## 使用方式

1. 在导航中选择功能模块
2. 根据需要切换子标签页
3. 查看分析结果和可视化图表

## 提示

- 此功能为独立单页应用（SPA），通过 `/villagesML` 路由加载
- 目前覆盖广东自然村数据，后续可能扩展至全国
