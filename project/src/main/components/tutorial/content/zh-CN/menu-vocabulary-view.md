# 词表展示

浏览和搜索所有协作者提交的词表数据，支持卡片、地图、表格三种展示模式。无需登录即可浏览全部数据。

![词表首页总览](/tutorial/menu-vocabulary/01-词表首页总览.webp)

## 搜索与筛选

顶部的输入框是词表展示的核心入口。输入关键词后，可以同时搜索标准词、方言词、音标、详细释义等字段，系统会自动匹配相关词条。

![词表展示输入页面](/tutorial/menu-vocabulary/36-词表展示输入页面.webp)

在下拉菜单中可以选择限定搜索范围，例如只搜索标准词或只搜索方言词：

![按字段筛选](/tutorial/menu-vocabulary/37-按字段筛选.webp)

点击输入框旁的齿轮图标，可以打开搜索配置面板，调整搜索匹配方式（如精确匹配或模糊匹配）：

![搜索配置齿轮](/tutorial/menu-vocabulary/38-搜索配置齿轮.webp)

除了关键词搜索，还可以按地点筛选数据，查看某个方言点的所有词条：

![按地点筛选](/tutorial/menu-vocabulary/39-按地点筛选.webp)

同时支持按行政区划筛选，方便批量查看同一区域下多个地点的词表数据。

## 卡片模式

默认展示模式。每条词条以卡片形式呈现，直观展示完整信息：

- **标准词**：通用说法
- **方言词**：当地方言的说法
- **音标**：方言词的实际发音
- **详细释义**：补充说明、例句或使用场景

![卡片模式浏览](/tutorial/menu-vocabulary/40-卡片模式浏览.webp)

卡片每页加载 50 条数据，滚动到底部后点击「加载更多」可继续浏览：

![卡片加载更多](/tutorial/menu-vocabulary/41-卡片加载更多.webp)

## 地图模式

切换到地图模式后，初始状态在地图上展示所有地点的词条数目分布，可以直观看到哪些地区词表数据更丰富。

![地图初始化展示](/tutorial/menu-vocabulary/42-地图初始化展示.webp)

可以像卡片模式一样在搜索框中输入关键词，也可以按标准词筛选地图上的数据。在左侧选框中选中某个标准词后：

![按标准词筛选地图](/tutorial/menu-vocabulary/43-按标准词筛选地图.webp)

系统会自动绘制地图，以圆点标注各地对该标准词的方言说法：

![筛选后自动绘图](/tutorial/menu-vocabulary/44-筛选后自动绘图.webp)

地图支持切换多种显示方式，可以从不同维度观察词表数据的地理分布：

- **按方言词显示**：地图上直接展示各地的方言词说法
- **按音标显示**：展示各地的实际读音
- **按地点显示**：仅展示地点名称

![切换显示方式](/tutorial/menu-vocabulary/45-切换显示方式.webp)

![地图显示方式切换](/tutorial/menu-vocabulary/46-地图显示方式切换.webp)

## 表格模式

表格模式以列表形式展示所有数据，与管理表格不同，这里展示的是全部数据，任何人都能查看，但不能编辑。

![表格展示模式](/tutorial/menu-vocabulary/47-表格展示模式.webp)

同样支持搜索、按列筛选、升序/降序排序等操作，方便快速定位感兴趣的数据。

## 提示

- 词表展示页面无需登录即可浏览全部数据
- 如果数据量大，善用地点筛选和行政区域筛选缩小范围
- 地图模式下选中标准词后，可以切换不同显示方式来对比空间分布
- 想要贡献或编辑词表，请切换到「导入词表」或「管理词表」标签
