# 方言地图

查看方言数据的空间分布，是查询和比较结果的地图展示页面。

![方言地图概览](/tutorial/menu-map-view/01-overview.webp)

## 页面来源

本页通常作为其他功能的结果展示目的地：

- 查字、查中古、查音位、查调等操作后切换到地图标签页查看
- 比较功能的结果直接在地图页展示
- 分区绘图的结果也在此展示

## 显示规则

地图绘图默认使用占比最高的音值；如果有多个音值占比差不多，会一起显示：

- 大于 50%：不带括号
- 35%~50%：带括号，但不带 `*`
- 20%~35%：带括号和星号（`*`）
- 小于 20%：不显示在地图上

![占比显示规则](/tutorial/menu-map-view/03-ratio-rules.webp)

![弹窗内细分查询](/tutorial/menu-map-view/05-popup-query.webp)

![查看地名开关](/tutorial/menu-map-view/06-show-names.webp)

## 模式切换

- **特征模式**：显示自定义特征数据，上方有特征下拉选单
- **比较模式**：显示比较结果，颜色标注相同/部分相同/不同
- **普通模式**：显示标准查询或分区绘图的点数据

## 自定义数据

登录后可开启「自定义数据」开关，在地图上同时显示公开数据和自己的数据。

## 提示

- 点击地图会把经纬度传给自定义数据面板，方便添加新数据
- 未登录时不能开启「自定义数据」开关
- 默认使用点聚合显示，放大后显示详细内容
