# 方言地图

查看方言数据的空间分布，是查询和比较结果的地图展示页面。

## 如何使用

本页通常作为其他功能的结果展示目的地：
- 查字、查中古、查音位、查调等操作后切换到地图标签页查看
- 比较功能的结果直接在地图页展示
- 自定义特征查询后自动跳转到此页

## 功能

- 在地图上显示方言点的读音或特征数据
- 支持点聚合显示，放大后显示详细内容
- 右上角开关切换显示地名标签
- 点击地图上的点弹窗查看详情
- 支持全屏展示，方便截图
- 可切换不同底图（街道图、地形图等）

## 模式切换

- **特徵模式**：显示自定义特征数据，上方有特征下拉选单
- **比较模式**：显示比较结果，颜色标注相同/部分相同/不同
- **普通模式**：显示标准查询或分区绘图的点数据

## 自定义数据

登录后可开启「自定义数据」开关，在地图上同时显示公开数据和自己的数据。

## 提示

- 点击地图会把经纬度传给自定义数据面板，方便添加新数据
- 未登录时不能开启「自定义数据」开关
