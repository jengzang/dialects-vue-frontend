# 地图绘制

在地图上自由绘制标注，适合制作方言地图或标注特定区域。

## 功能概述

- 在地图上绘制点、线、面等标注
- 支持泰森多边形（Voronoi）生成，可基于方言点绘制方言分布图
- 标注数据可导出为 GeoJSON
- 地图可导出为 PNG 图片

## 基本操作

1. 选择绘制工具（点/线/面等）
2. 在地图上进行绘制
3. 编辑和管理绘制的图层
4. 导出绘制结果

## 工作台

- 左侧图层列表管理所有绘制元素
- 支持图层的显示/隐藏、编辑、删除
- 绘制状态自动保存到本地存储

## 导出功能

- 导出为 GeoJSON 格式，可导入 GIS 软件
- 导出当前地图为 PNG 图片

## 提示

- 绘制的工作状态会自动保存，刷新不丢失
- 此功能适合配合分区绘图和查询结果使用
