# 地图绘制

在线编辑点、线、面和文字标注，管理图层与属性，利用方言点生成泰森多边形，并导出地图数据或图片。本教程按实际制作地图的顺序介绍工作台的功能、操作方法和使用限制。

## 开始之前

从「探索」进入「地图绘制」。未登录时可以查看功能面板；创建、编辑、导入等真实操作需要登录。按钮不可用时，先检查登录状态、当前图层和选择对象。

- **图层**：一组对象的容器，例如「调查点」「方言边界」。同一图层可以添加多个同类型对象。
- **要素**：图层中的一个点、一条线、一个面或一条文字标注。删除要素不等于删除图层。
- **顶点**：构成线或面的坐标点。删除顶点会重新连接相邻顶点，不是删除整条线或整个面。

当前活跃图层决定新增和编辑对象的归属。隐藏图层不能在地图上命中或绘制；锁定图层仍可显示和辨认，但不能修改。

## 工作台与推荐流程

「图层」面板管理图层；「绘图工具」提供选择、绘制、编辑和属性；「泰森多边形」生成方言分布区域。可以分别展开或收起。配置随工具和对象变化，线、面、文字的专用设置不会始终同时出现。

1. 登录，选择底图，把地图移动到目标地区。
2. 添加图层或导入数据，设置容易辨认的名称。
3. 绘制对象，或生成泰森多边形后导出到编辑图层。
4. 编辑顶点、检查几何质量，调整颜色和文字。
5. 保存本地草稿，并导出 GeoJSON 备份。
6. 在图片预览中检查构图，导出 PNG。

## 创建和管理图层

### 添加图层

1. 点击「添加图层」。
2. 选择新建点图层、文本标注图层、线图层或面图层；也可以导入文件、行政区划边界或河流水系。
3. 确认当前活跃图层，再在地图上操作。同一图层继续添加对象时，重新选择对应绘制工具即可，不必每次新建图层。

### 顺序、显示、锁定和名称

- 点击图层切换活跃图层。绘制前查看当前层名称，避免把对象画到其他层。
- 使用置顶、上移、下移、置底调整叠放顺序。面遮挡点线时，可把点线层移到上方。
- 显示/隐藏不删除数据，也可以显示全部或隐藏全部。隐藏活跃层会退出编辑，不能继续向隐藏层绘制。
- 锁定可保护参考数据；图层解锁后，单独锁定的要素仍需另行解锁。
- 图层标签开关控制文字显示；图层透明度控制整体透明程度，不等于面填充透明度。
- 重命名时 Enter 保存、Escape 取消。复制图层适合保留原始数据再做实验；删除图层会删除其中所有对象，请先备份。

## 绘制点、线和面

### 绘制点

选择可见、未锁定的点图层，点击「绘制点」，在地图单击创建点。需要更多点时继续使用点工具；选中点后修改名称、样式和属性。

### 绘制线和面

1. 选择对应图层，点击「绘制线」或「绘制面」。
2. 单击地图逐个添加顶点。鼠标移动时的末段是预览，不代表已确认的新点。
3. 线至少需要 2 个有效点，面至少需要 3 个有效点；面完成后维护首尾闭合。
4. 使用「完成绘制」或 Enter 提交；也可点击结束控制点，面可点击起点完成闭合。
5. 使用「取消草图」或 Escape 放弃本次未完成对象。

绘制中的撤销/重做只处理本次草图的已确认点；Backspace/Delete 撤回最后一个点。撤销后再添加点，会清除草图重做分支。

点数不足、自相交或零面积等问题可能阻止完成，请查看提示并调整。切换工具、图层或替换数据会取消未完成草图；请先完成绘制，不要把预览当成已保存要素。

## 选择对象与批量操作

### 地图点选和重叠候选

切换到「选择」，单击对象。多个对象重叠时，候选列表显示命中的图层、对象和权限，先辨认再选择。其他可见图层也可用于辨认，但查看只读或锁定候选不等于获得编辑权限；修改时应切换到所属图层并解锁。

隐藏对象不参与地图命中。切换图层后重新确认选择，不要根据旧高亮判断当前编辑对象。

### 面板勾选和框选

1. 在当前图层的要素列表勾选对象，建立多选集合。
2. 「全选可编辑」「反选可编辑」只处理符合编辑条件的对象。
3. 点击「框选可编辑」后拖出范围，选择当前活跃图层中的可编辑对象；不是跨全部图层的全局框选。
4. 「清空勾选」取消多选；Escape 可退出框选或清除选择。

批量操作包括显示、隐藏、锁定、解锁、删除勾选要素及移动到兼容图层。移动前检查目标层类型和状态。复制要素适合制作同类对象变体。

「删除顶点」「删除选中要素」「删除勾选要素」「删除图层」作用范围不同。直接编辑中选中了顶点，删除优先作用于顶点；操作前查看工作区目标。「清空全部」清空当前活跃图层中的要素，不是清空所有图层；它不是只删除勾选对象，确认前先导出备份。

## 编辑顶点与精确坐标

### 插入、移动和删除

1. 选中可编辑的线或面，进入形状编辑；工作区显示对象和所选顶点数。
2. 单击顶点选中，再拖动调整位置。
3. 点击边中点控制柄插入新顶点，再拖动它调整形状。
4. 选中顶点后点击删除顶点，或按 Delete/Backspace；系统重新连接剩余顶点，保持面环闭合，并选择邻近剩余顶点，便于连续编辑。
5. 点击「完成编辑」返回普通选择。

线不能删到少于 2 个有效点，面不能少于 3 个有效点；共享边界保护也可能阻止删除。查看失败原因，不要反复按删除绕过保护。

### 按坐标定位

只选中一个顶点时，填写经度、纬度并点击「应用坐标」。使用十进制度数，例如经度 `113.2644`、纬度 `23.1291`；经度在前，纬度在后。这是单顶点编辑，不是批量坐标转换。

### 撤销和重做

完成后的修改使用工作台历史；未完成绘制使用草图历史。顶点编辑的撤销/重做会恢复对应对象和顶点上下文，前提是目标仍存在、可见且可编辑。

历史不是永久版本管理；刷新或恢复草稿后不要依赖原来的撤销记录。重要修改前复制图层或导出备份。

## 吸附与共享边界

1. 在线、面绘制或顶点编辑的精度设置中开启「吸附」。
2. 按需启用已有顶点、边中点、线段/面边界、网格和参考图层。
3. 调整容差，单位为屏幕像素。过大容易吸到不想要的对象，过小则需要精确移动鼠标。
4. 网格尺寸单位为经纬度的「度」，不是米或像素。
5. 观察预览和目标提示，确认后落点或结束拖动。按住 Alt 可临时绕过吸附。

目标优先级为顶点、边中点、边、网格；参考图层开关决定是否使用其他可见层。锁定的可见层可以提供参考，不会因此被修改。行政边界导入后也可作为参考。

「同步共享顶点/边」用于支持的共享几何编辑；「保护共享边界」可阻止破坏共享位置的删除。这不是完整跨图层拓扑系统，也不是自动沿边追踪工具。编辑相邻区域后仍需检查缝隙和重叠。

## 几何工具

先选中符合条件的可编辑对象。工具不可用时检查类型、数量、顶点选择和图层状态。

### 线工具

- **反向几何**：反转坐标顺序，不会自动赋予道路流向等业务含义。
- **简化几何**：清理连续重复点和可移除的共线点，不是任意容差的曲线平滑。
- **闭合线**：连接末端到起点，结果仍然是线。
- **分割线**：进入顶点编辑，选中内部顶点后执行；端点不能作为有效分割位置。
- **闭合线转面**：对符合条件的闭合线转换，检查结果图层和面轮廓。

### 分割面

1. 选中待分割面。
2. 从切割线下拉框选择已有线，或点击「画线分割面」。
3. 切割线应穿过面，按正常线草图流程完成。
4. 检查结果，不满意时撤销；「取消画线」放弃切割草图。

### 合并、相交和差集

在当前层勾选至少两个符合条件的面：

- **合并面**：合并所选面，替换参与合并的对象；不相连部分可能形成多面结果。
- **求相交**：计算共同区域，替换主选中面的几何，其他面保留。
- **计算差集**：从主选中面减去其他所选面的覆盖部分，替换主选中面，其他面保留。先确认主选中对象，顺序影响结果。

没有可用结果或结果无效时会提示失败，不会把空结果当正常面保存。差集可产生孔洞，但没有独立「画洞」工具；多面结果也不等于完整 multipart 子部件编辑。

### 缓冲区

选中支持的对象，填写大于 0 的「缓冲距离（公里）」，生成缓冲区。结果替换该对象几何，并非自动另建缓冲层。点、线转面有图层兼容限制：当前层需只有该一个要素；多对象点线层可先复制目标到独立层。

缓冲、合并和差集前建议复制图层。当前没有独立平滑、沿边偏移、延伸到边界或炸开多部件工具。

## 几何质量检查与修复

1. 查看质量提示，展开问题列表。检查可能涉及重复点、无效坐标、未闭合环、自相交和零面积，具体以结果为准。
2. 查看对象名称及环、边、顶点位置，点击问题定位地图。
3. 手动移动、删除或插入顶点；有修复入口时可用「修复此要素」。
4. 检查形状与属性，不符合预期时撤销。

自动修复采用保守处理，不保证修复所有复杂几何。部分简单自相交面可能拆成多个面要素；复杂孔洞仍可能需要手动处理。质量提示不等于完成相邻区域无缝拓扑验证。

## 样式、属性与数据表

没有选中要素时查看图层设置；选中对象后查看要素设置，修改前确认目标。

- 点：填充色、描边色、半径。
- 线：线色、线宽。
- 面：填充色、填充透明度、描边。
- 图层：整体透明度、标签开关、可见和锁定。

想保留清晰边界而让底图透出，应降低面填充透明度，不是只降低整个图层透明度。

在要素属性中修改名称或字段。「要素数据表」显示名称、几何、状态和属性，可编辑支持修改的单元格。勾选目标后，用批量名称或字段和值操作统一修改。

使用有业务意义的字段，如「方言类别」「调查时间」。标识和内部保留字段不是普通业务字段。表格服务于当前层，不是跨全部图层的数据库查询。

## 文字标注

### 独立文字与对象标签

1. 独立文字：添加文本标注层，选择「添加文字」，在地图单击定位，再填写内容，适合标题和地区说明。
2. 对象标签：选中点、线、面，在标注文字中填写内容，适合调查点或区域说明，不必另建文本层。
3. 移动独立文字时选中调整位置；文字偏移改变相对锚点的位置，不等于改变数据坐标。

### 从字段生成标注

选择用于标注的属性字段，执行「从字段生成标注」。有勾选对象时只处理勾选的可编辑对象；没有勾选时处理当前层的可编辑对象。先检查字段和空值，生成后抽查，避免把内部编号当展示名称。文字为空不会自动产生可见标签。

### 排版、背景和引线

文字设置包括多行内容、字号、颜色、常规/粗体、水平对齐、锚点、旋转、行高、字间距和最大宽度。在输入区换行可分成多行，最大宽度也影响自动排版。

描边颜色与宽度提高文字可读性。背景框可设置颜色、透明度、内边距；引线可设置颜色和宽度，再用水平/垂直偏移把文字移开，让引线指向原位置。

最小/最大显示级别是地图缩放级别，不是 `1:50000` 比例尺分母。超出范围时标签不显示。

### 避让、优先级和诊断

避让可能使密集区的文字暂时消失。调整优先级、字号、位置或缩放级别；允许重叠可显示更多文字，但可能互相遮挡。

查看标注诊断。文字不可见时检查内容、图层标签开关、隐藏状态、缩放范围和碰撞。字体效果依赖字体资源加载，不是任意本机字体都能直接使用。

## 导入地图数据

### GeoJSON、JSON、KML、KMZ 和 CSV

1. 添加图层中选择导入，选择受支持的文件。
2. 阅读导入结果和诊断，核对成功数量、跳过对象及坐标问题。
3. 检查新层类型、位置、属性，再设置样式。

JSON 必须包含受支持的地理数据结构，不是任意 JSON。集合、多部件可能拆成多个对象，结果数量不一定等于源文件顶层记录数。

CSV 用于点数据，必须有经度和纬度列。经度支持 `lng`、`lon`、`longitude`、`x`、`经度` 等；纬度支持 `lat`、`latitude`、`y`、`纬度` 等。示例：

```csv
名称,经度,纬度,方言类别
调查点甲,113.2644,23.1291,粤语
调查点乙,114.0579,22.5431,客家话
```

投影平面坐标不能直接当经纬度；坐标系不一致也可能导致偏移，先转换并核对已知地点。普通 CSV 点导入和泰森表格导入是不同流程。

### 行政区划和河流水系

行政边界导入中选择国家、省、市或县等可用级别及地区，再确认。高精度模式需要加载对应选项和边界，数据更大、加载更慢；普通精度适合概览，高精度适合局部细节。可锁定导入的边界作为参考。

河流水系中勾选需要的数据级别，支持多选后确认。级别按面板的数据分类使用，不应自行解释为严格的水文学河流级序。

## 用泰森多边形制作方言分布图

泰森多边形按最近邻点划分区域，再按分区字段合并，适合调查点覆盖下的示意图。**计算边界不是已经证实的方言边界**，仍需结合山川、行政区、历史和调查材料判断。

### 数据来源与导入

1. 打开泰森面板，选择内置地图集或音典分区来源、分区级别。
2. 按研究需要设置方言岛显示；音典来源可使用面板的音典调整选项。设置会影响参与点和分组。
3. 查看总点、有效点、忽略点和分组数量。

自有数据支持 `.xlsx`、`.xls`、`.csv`。在预览中选工作表、表头，映射地点名称、经度、纬度及分区列，检查无效坐标、缺失分区和重复地点，再确认应用。要结合内置点，开启「同时使用官方分区数据」；只用自采点则关闭。

从村落数据工作流进入可使用传入的村落点和分组。先核对点数和分类，不要假设与内置方言点是同一套数据。

### 调整点和分组

- 「编辑合并字段」调整分组字段合并设置；确认后检查是否误合并不同类别。
- 「选择忽略点」排除不参与计算的地点，检查忽略统计。
- 「添加方言点」后点击地图，在分区选择中确认归属；可按分区管理和删除自加点。
- 「预览点位」查看参与点，检查远离研究区域的异常点。

修改数据、分组或忽略设置后，应重新计算。

### 生成与导出到图层

1. 设置默认方形范围或自动裁剪，按需调整延伸比例；延伸只改变外围计算范围，不增加调查证据。
2. 生成泰森多边形，等待并检查区域和分组。
3. 导出到图层时勾选分组，每次最多 20 组，可分批处理。
4. 需要行政边界裁剪时设置级别和地区，高精度边界需选择对应选项。
5. 确认后在图层面板检查面图层，再调整顶点、颜色、名称和文字。

预览不等于已保存的编辑图层；计算范围与导出时行政边界裁剪也不同。点稀疏、海岸和缺少调查的区域尤其需人工检查。

大量点与复杂边界仍消耗时间、内存和渲染资源。先在较小区域试算、减少分组并分批导出；后台计算不代表地图绝不会卡顿。

## 导出 GeoJSON

先完成或取消草图，选择导出当前图层或全部图层。全部图层汇总成一个 FeatureCollection，不保证保留工作台层级。

GeoJSON 可备份或导入其他 GIS。样式属性可随数据输出，但其他软件未必识别本项目颜色和文字配置，可能需要重新设置符号。保留工作台状态还需保存本地草稿。

## 导出 PNG 图片

1. 选择当前视图、选中图层、选中要素或自定义范围。
2. 选择当前尺寸、1080p、2K 或自定义宽高；尺寸受限制，过大会增加内存需求。
3. 选择当前或自定义缩放，设置是否包含底图、绘制图层，必要时只勾选指定层。
4. 进入预览，检查对象数量、尺寸和构图。自定义范围在预览地图拖拽框选；其他模式检查并调整视图。
5. 核对文字、遮挡和边缘裁切，确认导出。

选某层的范围不等于只导出该层，内容需单独勾选。吸附、质量定位等辅助提示不是最终地图内容，以预览为准。底图、字体和网络资源未加载时图片可能不完整；PNG 是静态成果，不能代替数据备份。

## 本地草稿与自动恢复

- 「保存到本地」：输入名称创建草稿。
- 「更新到本地」：选择已有草稿，以当前状态更新。
- 「从本地恢复」：选择并确认恢复；先备份当前工作。
- 「删除本地」：删除草稿，不是删除已导出的文件。

草稿保存图层、活跃层、底图及部分面板、吸附和拓扑设置，不包括所有临时输入、原始导入表格、未完成草图或撤销记录。

自动草稿可在重新进入时提示恢复，但存储额度、隐私模式、清理网站数据或换设备都会影响它。这不是云同步，不保证「刷新永不丢失」。保存失败时立即导出备份。

## 视图与快捷键

底图/视图设置中选择地图来源；用缩放按钮、滚轮和拖动调整视图。重置视图回到默认观察范围，全屏适合细节编辑，方向控制可恢复朝向。

快捷键用于地图工作区，输入框正常输入时不会抢占对应按键：

- `Ctrl+Z` / `Command+Z`：撤销，草图中撤回点。
- `Ctrl+Shift+Z` / `Command+Shift+Z`，或 `Ctrl+Y`：重做。
- `Enter`：完成线/面草图；重命名输入中保存名称。
- `Escape`：取消草图，或退出框选/清除选择；重命名中取消。
- `Delete` / `Backspace`：草图中撤回最后一点，顶点编辑中删除所选顶点，普通选择中删除可删除对象。
- `Ctrl+A` / `Command+A`：非草图状态全选当前可编辑对象。
- `Alt`：临时绕过吸附。

## 常见问题

### 看得到工具，但不能操作

检查登录、活跃层、可见和锁定状态，以及对象类型、数量和顶点选择。有些工具只在相应选择上下文显示。

### 隐藏后似乎仍有对象

检查重叠复制层、泰森预览或另一层独立文字。标签开关只关文字，不隐藏几何；要素隐藏和图层隐藏也不同。先辨认候选中的所属层。

### 无法删顶点或完成面

检查有效点数、共享边界保护、自相交、零面积提示，定位后调整或撤销。不要用删除整个对象代替一个顶点的调整。

### 文字时有时无

检查避让、优先级、缩放范围、标签开关和隐藏状态。允许重叠可显示更多文字，但通常需重新排版。

### 导入错位或数量改变

核对经纬度顺序、坐标系、CSV 列名、表格映射和诊断。无效行可能跳过，集合、多部件也可能拆分，不能仅凭数量判断数据丢失。

### 地图或导出变慢

隐藏不需显示的复杂层，减少密集标注，避免一次加载大量高精度边界。泰森分组分批导出，PNG 先用小尺寸验证。隐藏减轻显示负担，不保证降低所有后台计算开销。

### 怎样稳妥保存

结束草图后保存本地草稿并导出 GeoJSON，最后导出 PNG。三者分别保留工作台状态、地图数据、静态图片，不能互相替代。
