# 分区绘图

将方言点或分区直接绘制成点位地图，支持分区着色展示地理分布。

![分区绘图概览](/tutorial/menu-map-divide/01-overview.webp)

## 基本操作

1. 输入地点名称，或从分区选择器勾选分区
2. 选择显示的分区层级

地图集和音典分区都有三级，可以选择用于绘图的层级数：

![选择分区层级](/tutorial/menu-map-divide/04-select-level.webp)

输入地点或选择分区后，点击执行自动跳转到地图页：

![分区绘图输入界面](/tutorial/menu-map-divide/03-input.webp)

## 分区着色

不同分区以不同颜色标示，直观展示地理分布。比如按照二级分区绘制音典岭南、岭西分区：

![二级分区示例——音典岭南岭西](/tutorial/menu-map-divide/05-level2-example.webp)

![不同分区以不同颜色标示](/tutorial/menu-map-divide/06-colors.webp)

鼠标移至上方或单击，可查询具体地点名和分区信息：

![悬停查询地点名和分区](/tutorial/menu-map-divide/07-hover-detail.webp)

## 全部数据

勾选「使用全部数据」可一次性绘制全国分区图。使用专门优化的新接口，但数据量大时可能较卡：

![全国分区图——音典一级分区](/tutorial/menu-map-divide/02-national.webp)

![使用全部数据绘制全国](/tutorial/menu-map-divide/08-all-data.webp)

地图集一级分区效果：

![地图集一级分区](/tutorial/menu-map-divide/09-atlas-level1.webp)

## 提示

- 结果会直接跳转到地图页展示
- 注意分区的模式（地图集 vs 音典），画出来的范围可能不同
