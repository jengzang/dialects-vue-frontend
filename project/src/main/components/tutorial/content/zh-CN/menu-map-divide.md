# 分区绘图

将方言点或分区直接绘制成点位地图，支持分区着色展示地理分布。

## 基本操作

1. 输入地点名称，或从分区选择器勾选分区
2. 选择显示的分区层级（一级/二级/三级，地图集和音典分区各有三级）
3. 点击执行，自动跳转到地图页

## 分区着色

- 不同分区以不同颜色标示，直观展示地理分布
- 鼠标悬浮或单击可查询具体地点名和分区信息

## 全部数据

勾选「使用全部数据」可一次性绘制全国分区图：
- 使用的是专门优化的新接口，响应更快
- 数据量大时可能较卡

## 典型用例

- 按二级分区绘制音典岭南、岭西分区
- 地图集一级分区
- 音典一级分区
- 全国范围的方言分区对比

## 提示

- 结果会直接跳转到地图页展示，不留在本页
- 注意分区的模式（地图集 vs 音典），画出来的范围可能不同
