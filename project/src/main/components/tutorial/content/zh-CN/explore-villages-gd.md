# 广东自然村树状图

按行政层级浏览广东自然村数据，支持树状展开和方言地图可视化。

数据来源：《全粤村情》方言数据（均为站长录入），注意存在行政区划对应、调查精确度、人工录入等误差来源。

## 基本操作

1. 页面加载市級清单
2. 点击目标市卡片上的「载入」
3. 逐级展开树状结构：市 → 区县 → 乡镇 → 行政村 → 自然村
4. 点击节点右侧的 🌍 打开地图弹窗

## 节点信息

最底层自然村节点显示：
- 村名
- 方言分布
- 经纬度（如有）

## 搜索

- 搜索框只比对已载入的节点
- 命中节点的高层路径自动展开
- 命中文本高亮显示

## 地图功能

- 点击分支节点的 🌍：递归收集所有下属自然村并绘制
- 点击底层节点的 🌍：仅显示该村
- 地图弹窗支持切换底图、重设视角、全屏
- **方言模式**：以不同颜色标示不同方言，不聚合
- **村名模式**：点聚合显示

## 提示

- 看不到村落通常是因为该市还没按「载入」
- 地图上点数少于树节点数是因为部分村落没有经纬度
- 目前只有广东省数据
- 瓦片地图源在国外，可能需要科学上网
