# 音值比较

比较所选各点的音值对应关系。

## 基本操作

1. 输入地点2~5个
2. 滑动选择连线最少字数和节点最少字数
3. 选择是否优化连线、是否忽略多音字
4. 点击「开始比较」
![音值比较1.png](/tutorial/menu-compare-phonetic/音值比较1.webp)

## 结果解读

1. 更直观地比较所选各点的音值对应关系
2. 可切换声母、韵母或声调进行比较
![音值比较2.png](/tutorial/menu-compare-phonetic/音值比较2.webp)
3. 点击音值会弹窗显示对应音值所有的汉字
![音值比较3.png](/tutorial/menu-compare-phonetic/音值比较3.webp)
![音值比较4.png](/tutorial/menu-compare-phonetic/音值比较4.webp)
4. 点击连线会弹窗显示两地音值对应的汉字
![音值比较5.png](/tutorial/menu-compare-phonetic/音值比较5.webp)

## 适用场景

- 比较两个音值在不同区域的分布差异
- 配合查音位进行音类分合分析

## 提示

- 此功能侧重音值的对应关系
- 如需了解音值的中古来源，先用「查音位」
- 如需比较汉字读音，用「比较汉字」
