# 管理词表

对自己的词表进行在线编辑、批量替换、增删词条等操作。编辑权限的用户只能更改自己提交的词条。

![编辑功能概览](/tutorial/menu-vocabulary/18-编辑功能概览.webp)

## 创建词条

点击新增按钮后，弹窗填入数据。标准词必填，方言词和音标二者填入其一即可。

![创建词条弹窗](/tutorial/menu-vocabulary/19-创建词条弹窗.webp)

## 删除词条

点击最右侧的红色 × 按钮，确认弹窗后即可删除。

![删除词条确认](/tutorial/menu-vocabulary/20-删除词条确认.webp)

## 批量编辑单元格

进入编辑模式后，可以像 Excel 一样自由更改单元格。最后点击右上角的「提交」即可保存。

![批量编辑单元格](/tutorial/menu-vocabulary/21-批量编辑单元格.webp)

## 批量替换

进入编辑模式后，点击右上角「批量替换」按钮。

![批量替换按钮](/tutorial/menu-vocabulary/22-批量替换按钮.webp)

先选择要批量替换的列：

![批量替换选择列](/tutorial/menu-vocabulary/23-批量替换选择列.webp)

然后输入待替换的内容和替换后的内容。有两种匹配模式：

- **完全匹配**：只有当整个单元格与查找内容完全一致时才替换。例如查找「广州」，只有「广州」会被替换，「广州市」不会
- **包含匹配**：只要单元格内任意位置包含查找内容即替换。例如查找「广州」，则「广州」、「广州市」、「广州话」都会被替换

输入完成后先点击「预览」：

![批量替换预览](/tutorial/menu-vocabulary/24-批量替换预览.webp)

可以选择「仅替换当前分页」或「全表替换」。建议使用仅当前页替换，可以预览到具体替换内容：

![替换当前分页预览](/tutorial/menu-vocabulary/25-替换当前分页预览.webp)

全表替换无法预览，不太建议使用：

![全表替换提示](/tutorial/menu-vocabulary/26-全表替换提示.webp)

确认后点击「替换」按钮：

![确认替换](/tutorial/menu-vocabulary/27-确认替换.webp)

替换完成：

![替换结果](/tutorial/menu-vocabulary/28-替换结果.webp)

![替换完成](/tutorial/menu-vocabulary/29-替换完成.webp)

## 筛选与排序

**按列筛选**：点击列名即出现筛选弹窗，勾选要筛选的值即可过滤数据。

![按列筛选](/tutorial/menu-vocabulary/30-按列筛选.webp)

**排序**：点击列名旁的箭头可进行升序或降序排序。

![排序功能](/tutorial/menu-vocabulary/31-排序功能.webp)

## 更新地点信息

如果地点信息需要更新，可以在地点信息页面进行更改。

![更新地点信息页面](/tutorial/menu-vocabulary/32-更新地点信息页面.webp)

点击编辑会弹出编辑窗口：

![编辑地点弹窗](/tutorial/menu-vocabulary/33-编辑地点弹窗.webp)

## 管理权限

拥有管理权限的用户可以查看详细的编辑日志：

![编辑日志](/tutorial/menu-vocabulary/34-编辑日志.webp)

必要时可以进行回滚操作：

![管理回滚](/tutorial/menu-vocabulary/35-管理回滚.webp)

同时，数据库每小时自动备份一次，即使改坏了也能及时恢复。

## 提示

- 编辑模式下修改后别忘了点击「提交」保存
- 批量替换建议使用「仅替换当前分页」模式，可以预览确认替换内容
- 管理权限用户可以查看编辑日志并进行回滚
