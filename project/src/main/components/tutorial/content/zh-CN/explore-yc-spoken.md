# 阳春口语

展示阳春地区的口语语料数据，以表格形式呈现本字考、IPA 读音、粤拼、词性、释义及例词例句。

## 数据特点

相比全粤村情数据，阳春数据所用更多为本字（而非同音字），数据经过站长核对，更为准确。

## 主要栏位

- 本字考
- IPA
- 粤拼
- 来源
- 声母、韵母、音调
- 词性
- 释义
- 例词例句
- 待校及说明

## 使用方式

- 用表格筛选器按栏位过滤数据
- 可点击标题旁的村落按钮跳转到阳春自然村页面
![阳春口语.webp](/tutorial/explore-yc-spoken/阳春口语.webp)

## 提示

- 不是所有栏位都支持筛选（IPA、粤拼、释义、例句等不可筛选）
- 适合阳春方言研究者深入查阅
