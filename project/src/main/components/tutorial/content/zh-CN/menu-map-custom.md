# 自定地图

管理自己的自定义方言特征数据，并将其绘制到地图上。用户的自定义数据仅本人可见，与账号绑定，在不同设备登录也能使用。

## 补充自定义数据

适用于补充档案中缺少的方言点或特征数据。例如档案里的东莞方言点数据有限，而用户本人对东莞的流摄了解较多，便可以自己补充数据：

![档案里的东莞流摄数据](/tutorial/menu-map-custom/03-dongguan-before.webp)

补充个人数据后，地图上多出了莞城、厚街等方言点：

![补充个人数据后](/tutorial/menu-map-custom/04-dongguan-after.webp)

### 添加方式

在地图页面的右侧面板，可以添加自定义数据，此时会自动填写好类别、当前查询特征：

![在 map/view 页面右侧面板添加自定义数据](/tutorial/menu-map-custom/05-view-panel-add.webp)

填写流程：

1. **地点简称**：填入要补充的地点简称
2. **分区**：如果地点存在于档案里，会自动匹配填入分区；否则需手动填写。推荐分区与音典档案保持一致，方便后续搜索（如填入「岭南-珠江-莞宝」，以后输入岭南/珠江/莞宝都能搜到）
3. **坐标**：点击地图即可自动填入经纬度
4. **类别、当前查询特征**：根据页面自动识别，无需手动填入
5. **值**：显示在地图上的值
6. **说明**（可选）：在地图上点击自定义地点时弹窗显示

填写完成后点击提交：

![点击提交数据](/tutorial/menu-map-custom/06-view-panel-submit.webp)

## 搜索特征

登录后可在搜索框中搜索已有特征名称，选中后点击查询跳到地图页查看。
