# 自定地图

管理自己的自定义方言特征数据，并将其绘制到地图上。用户的自定义数据仅本人可见，与账号绑定。

## 补充自定义数据

![自定地图面板](/tutorial/menu-map-custom/overview.jpg)

*添加自定义数据面板*

适用于补充档案中缺少的方言点或特征数据。例如档案里的东莞方言点数据有限，可自己补充。

### 添加流程

1. 填入地点简称
2. 如果地点存在于档案里会自动匹配分区；否则需手动填写分区。推荐分区与音典档案保持一致，方便后续搜索
3. 坐标：点击地图自动填入
4. 类别和当前查询特征：根据页面自动识别
5. 值：显示在地图上的值
6. 说明（可选）：在地图上点击自定义地点时弹窗显示

## 管理数据

在自定义页面可：
- 按调查点整理个人数据，针对单个方言点不断补充
- 按方言特征整理，针对某一待比较特征不断补充方言点
- 点击卡片后单独绘制自定义数据

## 数据入口

- **逐条新增**：跳转到地图页并自动打开填写面板
- **批量新增**：跳转到个人数据管理页（`/auth/data`）

## 搜索特征

登录后可在搜索框中搜索已有特征名称，选中后点击查询跳到地图页查看。

## 提示

- 需登录才能使用
- 按查询后会自动跳转到地图页显示
- 帮助按钮内有欄位说明和格式示例
