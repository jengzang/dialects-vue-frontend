# 比较调类

比较两个调类在各方言点是否合流。适合用来分析特定区域内的调类归并现象。

## 基本操作

![比較調類——珠三角陽上、陰去合併](/tutorial/menu-compare-tone/01-overview.jpg)

![南方方言陰入、陽入合併情況](/tutorial/menu-compare-tone/02-overall.jpg)


1. 在调类勾选区勾选第一个调类（如阴上）
2. 再勾选第二个调类（如阳上）
3. 输入地点或分区
4. 点击「比较」，直接跳转到地图页面

## 结果解读

地图上以颜色标注两个调类的关系：

- **已合流**：两个调类调值完全相同
- **可能合流**：调值接近，有合并倾向
- **未合流**：调值明显不同
- 灰色：无数据

## 典型用例

- 珠三角一带的阳上、阴去合并情况
- 客家话阴平、阴去合并情况
- 南方方言的阴入、阳入合并情况
- 四邑、莞宝的阴平、阴去、阳上调类格局

## 限制

- 一次只能比较 2 个调类，选满后其他调类自动禁用
- 需取消已选中的某个调类才能更换组合

## 提示

- 有些方言点资料中没有注明某些调类（如阳上），会显示无数据
- 如需查看完整调类系统，先用「查调」
- 可一次性分析多个地点，观察区域性的调类归并趋势
