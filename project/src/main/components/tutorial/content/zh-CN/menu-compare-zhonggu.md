# 比较中古

将两组中古条件进行对比，直接看它们在各地的读音是否相近或差异明显。

## 基本操作

1. 选择比较维度：声母、韵母或声调
2. 在中央条件编辑区组出第一组中古条件
3. 点击「加入组 1」
4. 修改条件，组出第二组条件
5. 点击「加入组 2」
6. 输入地点或分区，点击「比较」

## 核心交互

- **中央区**是条件编辑区
- **组 1 / 组 2** 是待比较的条件集合
- 每次点击「加入」是把当前条件做成快照存进对应组
- 修改中央条件不会自动更新已加入的项目

## 支持复杂条件

每组可加入多条条件。例如比较宕江分合情况：
- 组 1：宕摄字
- 组 2：江摄字
- 可同时加入多组条件进行综合比较

## 相似度算法

对于某个中古特征，系统计算两组在各地的读音分布重叠度：

- 两组中相同的读音，取各自占比的最小值，全部求和即为总相似度
- 重叠度 ≥ 阈值 → 绿色（高度一致）
- 中等重叠 → 黄色（部分相似）
- 低重叠 → 红色（差异明显）

同一地点内部比较时，该算法更为可靠（因为同一地点音值不同即意味着音类不同）。

## 提示

- 同一组内所有条件的「排除」设置必须一致
- 第一次使用建议每组只放一条条件，确认流程后再增加
- 想先单独查看某组条件的结果，先用「查中古」各自查一遍
