# 查字

输入汉字和地点，查看该字在不同方言点的具体读音。

## 基本操作

1. 在输入框中键入要查询的汉字（支持繁简）
2. 在下方地点/分区区域选择方言点或分区
3. 点击「运行」按钮，自动跳转到结果页面

## 结果页面

- 每个方言点显示该汉字的具体读音（IPA）
- 多音字会展示多个读音
- 颜色标注文白读：红色为文读、蓝色为白读、黑色为普通读音
- 点击地名可弹窗查看该方言点的详细信息
- 点击音值可反查音节来源

## 地图页面

切换到地图标签页后：

- 地图上每个点显示该汉字在该地的最常见读音
- 点击地图上的点可弹窗查看详情
- 右上角可切换显示地名标签
- 地图支持全屏展示，方便截图
- 可切换不同底图（街道图、地形图等）

## 筛选与统计

在结果页面中：
- 可筛选特定音值，只显示匹配的数据
- 点击统计按钮可按声母/韵母/声调细分查询
- 点击详情按钮可查看汉字的详细音韵信息

## 提示

- 一次可查询多个汉字
- 地点支持模糊匹配，输入简繁均可
- 输入行政区划名称可匹配该区域所有方言点
- 与查中古不同：查字以汉字为出发点，直接看读音
