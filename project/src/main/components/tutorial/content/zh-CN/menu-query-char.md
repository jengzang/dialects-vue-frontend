# 查字

输入汉字和地点，查看该字在不同方言点的具体读音。

![输入页面](/tutorial/menu-query-char/01-输入页面.webp)

## 基本操作

1. 在输入框中键入要查询的汉字（支持繁简）
2. 在下方地点/分区区域选择方言点或分区
3. 点击「运行」按钮，自动跳转到结果页面

![输入汉字和地点](/tutorial/menu-query-char/02-输入汉字和地点.webp)

## 结果页面

点击运行后自动跳转到结果页面，即可查看汉字的详细读音。每个方言点显示该汉字的具体读音（IPA），多音字会展示多个读音。

![结果页面读音](/tutorial/menu-query-char/03-结果页面读音.webp)

### 文白读颜色标注

部分字表支持文白读颜色标注：
- 红色：文读
- 蓝色：白读
- 黑色：普通读音

![文白读颜色标注](/tutorial/menu-query-char/04-文白读颜色标注.webp)

## 地图页面

切换到地图页面，可看到读音的地理分布。地图上每个点显示该汉字在该地的最常见读音。

![地图读音地理分布](/tutorial/menu-query-char/05-地图读音地理分布.webp)

点击地图上的点可弹窗查看注释详情。

![地图点击查看注释](/tutorial/menu-query-char/06-地图点击查看注释.webp)

也可打开「查看地名」开关显示各地名称。

![地图显示地名](/tutorial/menu-query-char/07-地图显示地名.webp)

## 提示

- 一次可查询多个汉字
- 地点支持模糊匹配，输入简繁均可
- 输入行政区划名称可匹配该区域所有方言点
- 与查中古不同：查字以汉字为出发点，直接看读音；与查音位不同：查音位是从读音倒推来源
