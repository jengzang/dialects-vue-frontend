# 字表检查

上传方言字表文件，自动检查「非单字」「异常音标」「缺声调」等常见问题，并提供在线编辑修正功能。

## 基本操作

1. 登录账号
2. 选择数据格式（音典、跳跳老鼠、县志）
3. 上传文件（支持 .xlsx、.xls、.doc、.docx、.tsv，单文件上限 3 MB）
4. 系统自动分析并展示错误统计

## 检查功能

- **非单字检查**：检测是否包含非单字内容
- **异常音标检查**：检测 IPA 音标格式异常
- **缺声调检查**：检测缺少声调的音节

## 统计与筛选

- 左侧整理错误类型、调值统计、声母与韵母统计
- 点击错误列自动跳转到对应数据行
- 点击声母或韵母统计可直接筛选
- 搜索框支持快速定位

## 编辑模式

切换到编辑模式后：
- 可直接修改单元格值
- 可标记整列删除
- 支持 IPA 批量替换
- 支持入声调/舒声调批量替换
- 批量储存后系统重新分析最新内容
- 完成后下载更改后的文件

## 提示

- 格式选错会整份资料错误拆栏，上传前务必确认
- 退出编辑模式时未储存的修改会被清空
- 服务器做了限流，上传加载较慢请耐心等待
