# 上传音频

Praat 声学分析的入口。上传语音文件或直接录音，截取分段后开始分析。

## 功能简介

网站集成了 Praat 核心算法（基于 `praat-parselmouth` Python 包），提供现代化的网页界面进行声学分析。相比桌面版 Praat，操作更为简便，移动端和桌面端均可使用。

**需要登录**才能使用（因 Praat 算法非常消耗 CPU，服务器性能有限）。

## 上传语音

- 拖动文件或点击「选择文件」上传
- 支持 WAV、MP3、M4A、WebM、OGG、FLAC、AAC 等多种格式，无需预先转换
- 也可以直接在网站上录音，无需预先准备文件

![拖拽文件上传弹窗](/tutorial/explore-praat-upload/02-upload-dialog.webp)

手机录音音质通常好于电脑自带麦克风，推荐使用手机录制后上传：

![手机录音界面](/tutorial/explore-praat-upload/05-mobile-record.webp)

## 截取分段

上传后可在波形预览区拖动截取分段：

![波形图截取分段](/tutorial/explore-praat-upload/03-waveform-segment.webp)

- **自动模式**：系统自动切段，可在多段间切换选择
- **手动模式**：在波形上拖动选取区间（仅单段原音且总长不超过 10 秒时可用）
- 手动区段全部清空后会自动回到原始片段集合
- 只有当前选中的片段会进入分析

对于需要精确分析元音的情况，应当使用单音节模式，仔细截取语音部分并确认无杂音：

![单音节模式精确截取](/tutorial/explore-praat-upload/04-single-syllable.webp)

## 分析模式

- **单音节模式**：截取一个具体音节，分析最精确。适合元音分析和精确基频定调
- **连续语流模式**：上传一段语流，后端自动分段。适合基频定调，可一次上传多个调类；但用于元音空间分析时误差较大

## 分析设置

![七个分析模块详情](/tutorial/explore-praat-upload/07-analysis-modules.webp)

- **分析模块**（共七种）：基本信息、基频分析、强度分析、共振峰分析、音质分析、音段分析、频谱图分析
- **基本信息**：音频时长、采样率
- **基频分析**：调值特征、五度标调计算、基频曲线——基频定调依赖此模块
- **强度分析**：平均强度（dB）、强度范围、强度轨迹
- **共振峰分析**：共振峰轨迹——元音空间依赖此模块
- **音质分析**：谐噪比（HNR）、基频微扰（jitter）、振幅微扰（shimmer）
- **音段分析**：单音节模式拆分为 rime_core（韵核）和 syllable_like；连续语流拆分为 voiced、speech、silence
- **频谱图分析**：频率-时间二维能量分布，仅支持 3 秒以内语音
- **分辨率**：快速、标准、高精度三种模式

完成后点击开始分析，上传较慢请耐心等待。
