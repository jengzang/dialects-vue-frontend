# 查调

这一页是最简单的查询页之一：不用先输入字，也不用组中古条件，只要决定查哪些地点或分区，就能直接查看各地的调值 / 调类资料。

## 你在这一页会看到什么

- 这个分页本身没有额外的上方条件区。
- 主要可操作内容就是下方的地点 / 分区输入元件。
- 按下运行后，系统会跳到结果页，结果页再以「查调」模式载入资料。

## 最适合新手的操作顺序

1. 先选几个你想看的地点，或先选一个分区。
2. 第一次使用时，建议不要一下子放太多地点，否则调值表会很分散。
3. 按运行后到结果页查看调类、调值与不同地点的对应关系。

## 这一页有哪些实际规则

- 这页不需要额外选条件，真正的核心限制就是地点 / 分区。
- 执行时只会把 locations、regions、region_mode 带到结果页。
- 进结果页后，会由结果页呼叫查调 API，所以你在本页按完按钮后看到的是「跳转」，不是本页内部刷新。

## 新手怎么用最不容易乱

- 若你只想知道某几个点的声调系统，直接输入地点最快。
- 若你想看一整片区域的声调分布，先选分区再读结果。
- 如果资料太多，先把范围缩小，再观察调类名称和调值，不要一开始就全域阅读。

## 新手最常见的卡点

- 看不出差别：通常是地点太多，先缩小范围。
- 不知道先看调类还是调值：可以先看分类名称，再看具体数字。
- 以为这页没有内容：其实它是「用地点直接查调」的快捷入口，重点不在上半部，而在地点条件与结果页。

## 什么时候改用别的页面

- 想比较两个调类是否合流：改用「比较调类」。
- 想从字或中古条件切入：改用查字、查中古或查音位。
