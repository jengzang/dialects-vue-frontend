# 查调

查询方言点的声调系统，以表格形式直观展示调值、调类归并情况。

## 基本操作

查调只需输入地点或分区，无需其他条件。这是一个非常轻量的接口，响应速度较快。

![输入页面](/tutorial/menu-query-tone/01-输入页面.webp)

登录用户可以不受限制地同时查询多个地点。

![登录用户多地点查询](/tutorial/menu-query-tone/02-登录用户多地点查询.webp)

## 结果页面

结果以表格形式呈现，可以直观地看出调值、调类归并的情况。每行对应一个调类（阴平、阳平、阴上、阳上、阴去、阳去、阴入、阳入等），单元格显示具体调值（如 55、213、31 等）。同一列多个相同调值表示调类合并。

![结果表格调值调类](/tutorial/menu-query-tone/03-结果表格调值调类.webp)

点击地名后可查看详细的调值信息。

![点击地名调值详情](/tutorial/menu-query-tone/04-点击地名调值详情.webp)

## 地图页面

结果也会绘制在地图中，可切换不同调类进行绘制，地图上绘制的是具体调值。

![地图模式切换调类](/tutorial/menu-query-tone/05-地图模式切换调类.webp)

如果有调类合并情况，点击后会弹窗显示归并情况。

![调类合并弹窗](/tutorial/menu-query-tone/06-调类合并弹窗.webp)

## 提示

- 想看某两个调类是否合并，可以直接在表格中对比两行
- 地图模式可直观看出调值的区域分布特征
- 如需深入比较调类合流情况，可使用「比较调类」功能
