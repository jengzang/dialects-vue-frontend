# 查调

查询方言点的声调系统，以表格形式直观展示调值、调类归并情况。

## 基本操作

1. 输入地点或分区（只需输入地点，无需其他条件）
2. 点击「运行」

## 结果页面

- 以表格形式展示各方言点的调值
- 每行对应一个调类（阴平、阳平、阴上、阳上、阴去、阳去、阴入、阳入等）
- 单元格显示具体调值（如 55、213、31 等）
- 可直观看出调类的合并情况（如同一列多个相同调值表示合并）
- 点击地名可弹窗查看详细的调值信息

![查調結果——調值表格](/tutorial/menu-query-tone/02-result.webp)

## 地图页面

- 可切换不同调类在地图上绘制
- 地图上的数字是具体调值
- 如有调类合并情况，点击弹窗显示归并详情

![地圖模式——調值區域分布](/tutorial/menu-query-tone/03-map.webp)

## 特点

- 这是非常轻量的接口，响应速度较快
- 登录用户可不受限制地同时查询多个地点
- 适合快速对比多个方言点的声调系统

## 提示

- 想看某两个调类是否合并，可以直接在表格中对比两行
- 地图模式可直观看出调值的区域分布特征
- 如需深入比较调类合流情况，可使用「比较调类」功能
