# 登录

使用邮箱或用户名登录「方音图鑑」。任何人都可免费注册。

## 登录方式

支持两种登录方式，可点击切换：
- **邮箱登录**：邮箱 + 密码
- **用户名登录**：用户名 + 密码

## 基本操作

1. 选择登录方式
2. 输入对应的账号和密码
3. 点击登录

## 登录后

- 如果是从受保护页面被导来的（如 Praat 分析），登录成功后会回到原页面
- 否则自动刷新页面，同步登录状态
- 可使用个人数据存储、自定义数据等需登录的功能

## 没有账号？

点击底部的「没有账号？」链接可切换到注册页面。注册只需邮箱 + 密码 + 用户名。

## 提示

- 切换登录方式时密码栏会被清空（设计如此）
- 密码至少需要 6 位
- 账号/密码错误时会显示登录失败提示
