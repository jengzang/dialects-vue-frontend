# 结果页

查询和比较操作的结果展示页面。本身不发起查询，而是承接其他页面的查询参数并渲染结果。

## 从哪里来

- **查字**（tab1）：传入汉字和地点，展示各地方言读音
- **查中古**（tab2）：传入中古条件，展示符合条件字的各地读音
- **查音位**（tab3）：传入音位值，展示中古来源分布
- **查调**（tab4）：传入地点，展示调值调类表格

不同来源模式展示不同的结果组件：
- 查字与查调走 `CharsAndTones` 类型画面
- 查中古与查音位走 `ResultList` 类型画面

## 结果交互

- 点击地名弹窗查看方言点详细信息
- 点击音值弹窗反查音节来源
- 筛选功能按特定音值过滤数据
- 统计按钮按声母/韵母/声调细分查询
- 详情按钮查看汉字的详细音韵信息

## 切换标签

结果页顶部有标签可切换：
- **表格结果**：以表格形式展示
- **地图结果**：在地图上展示空间分布

## 加载状态

- 加载过程中显示计时器
- 超过 30 秒出现长等待提醒，说明查询范围较大

## 提示

- 结果页依赖 `globalPayload`，没有前一步查询数据时不会有结果
- 如果结果方向不对，回原查询页改条件；方向对了再去地图页看空间分布
