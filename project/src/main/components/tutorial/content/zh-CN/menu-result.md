# 结果页

查询和比较操作的结果展示页面。本身不发起查询，承接其他页面的查询参数并渲染结果。

![结果页总览](/tutorial/menu-result/01-overview.webp)

## 从这里来

- **查字**：传入汉字和地点，展示各地方言读音
- **查中古**：传入中古地位，展示符合条件字的各地读音
- **查音位**：传入音位的音值，展示中古来源分布
- **查调**：传入地点，展示调值调类表格

## 结果交互

### 点击与弹窗

- **点击地名**：弹窗查看方言点详细信息
- **点击音值**：弹窗反查音节来源，支持同时查多个音节（不同地点也可）

![点击音值弹窗](/tutorial/menu-result/07-syllable-popup.webp)

- **点击左下角地点列表**：可滑动跳转到对应地点，点击后滚动到目标位置
- **多音字**：会展示多个读音

![多音字展示](/tutorial/menu-result/02-duoyin.webp)

### 细分查询

- **点击地位**：可对当前结果的某个地位再次细分查询

![点击地位细分](/tutorial/menu-result/05-status-click.webp)

- **多小窗并列**：支持开多个弹窗，不断细分查询，方便同时对比

![多小窗对比](/tutorial/menu-result/06-multi-window.webp)

### 统计与详情

- **统计按钮**：对当前结果按声母/韵母/声调再次细分查询（如当前查韵母，点统计后可看声母分布）

![统计按钮](/tutorial/menu-result/03-statistics.webp)

- **详情按钮**：查看汉字的详细音韵信息

![详情按钮](/tutorial/menu-result/04-detail.webp)

### 筛选

- 支持按特定音值过滤数据，只保留想看的内容

## 显示模式

点击右下按钮切换展示密度：

- **全显模式**：方框包着汉字，所有地位均显示
- **主体模式**：仅一行展示汉字，自动筛掉占比过低或字数过少的地位，更节省空间

![显示模式切换](/tutorial/menu-result/08-display-mode.webp)

## 文白读标记

部分字表支持文白读颜色标记：

- **红色**：文读
- **蓝色**：白读
- **紫色**：文白读共用此声/韵/调
- **绿色**：纯粹的多音字，非文白读

![文白读颜色标记](/tutorial/menu-result/09-wenbai.webp)

查字结果中：蓝色白读、红色文读、黑色普通汉字。

## 加载状态

- 加载过程中显示计时器
- 超过 30 秒出现长等待提醒，说明查询范围较大

## 提示

- 结果页依赖前一步查询数据，没有传入参数时不会有结果
- 如果结果方向不对，回原查询页改条件；方向对了再去地图页看空间分布
