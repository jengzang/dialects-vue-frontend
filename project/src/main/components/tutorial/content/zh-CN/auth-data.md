# 我的数据

管理自己上传的自定义方言数据。支持批量新增、编辑、删除。

## 基本操作

1. 需登录才能访问
2. 页面显示所有已上传的自定义数据
3. 右上角显示总笔数和已选笔数

## 单笔编辑

点击每行右侧的「编辑」按钮，打开编辑弹窗，修改后储存。

## 批量新增

- 点击「批量新增」打开弹窗
- 可逐行添加，或直接粘贴 Tab 分隔、换行分笔的数据
- 每笔数据包含：简称、音典分区、经纬度、声韵调、特征、值、说明
- 必填欄位完整才能提交
- 一次最多提交 50 笔

## 批量编辑

1. 勾选要修改的数据
2. 点击「批量编辑」
3. 在弹窗中修改后提交

## 批量删除

1. 勾选要删除的数据
2. 点击「批量删除」
3. 确认后执行

## 搜索与分页

- 搜索框即时筛选表格数据
- 分页大小可切换 10/20/50/100
- 表头全选只选当前页的数据

## 提示

- 批量编辑实际是先删后建，提交前请确认数据完整
- 返回按钮跳转到 `/auth`，不是浏览器后退
