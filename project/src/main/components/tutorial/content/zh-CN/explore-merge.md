# 字表合并

按参考表的汉字顺序，批量合并多个字表文件。

## 三步流程

![字表合并界面](/tutorial/explore-merge/overview.jpg)

*字表合并——三步骤流程*

### 步骤 1：准备参考表

- 上传或使用默认参考表
- 参考表必须有「单字」列，其顺序即为最终合并顺序
- 支持上传自定义参考表（.xlsx、.xls，上限 3 MB）
- 可预览默认参考表后一键套用

### 步骤 2：上传待合并文件

- 一次可选多个文件（最多 20 个）
- 上传的字表需满足列名要求：
  - 汉字列：「單字」、「phrase」、「单字」、「漢字」、「汉字」
  - 音标列：「IPA」、「ipa」、「音標」、「音标」、「syllable」
  - 注释列：「注释」、「注釋」、「解釋」、「notes」
- 每个文件可单独移除

### 步骤 3：合并与下载

- 点击「开始合并」，显示进度
- 参考表之外的字会在末尾补充
- 一字多音以「;」分隔
- 注释存为 Excel 批注
- 完成后下载合并结果

## 提示

- 需登录才能使用
- 原始数据质量不佳时建议先去「字表检查」整理
- 可点击「重设」清除所有步骤重新开始
