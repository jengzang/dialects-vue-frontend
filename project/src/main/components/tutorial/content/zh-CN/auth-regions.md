# 自定义分区

创建和管理自己的方言分区方案，用于地点搜索和地图绘制时的区域筛选。

## 基本操作

1. 登录后访问此页
2. 查看已有分区列表（每张卡片显示分区名称、地点数、创建日期、描述）
3. 点击「新增」创建分区

## 创建分区

1. 填写分区名称
2. 手动输入地点或通过「选择地点」按钮添加地点
![分区1.webp](/tutorial/auth-regions/分区1.webp)
![分区2.webp](/tutorial/auth-regions/分区2.webp)
![分区3.webp](/tutorial/auth-regions/分区3.webp)
3. 手动输入时用空格或换行分隔地点，系统自动去重
4. 每个分区最多 1000 个地点
5. 地点数 ≥ 1 且名称非空时才能储存

## 编辑与删除

- 点击卡片上的铅笔按钮进入编辑（分区名称不可修改）
- 点击卡片上的垃圾桶按钮可以删除，删除分区前会弹出确认框

## 应用场景

- 自定义分区可在查询、比较等功能中作为地点筛选条件
- 与账号绑定，不同设备登录均可使用
- 配合自定义数据使用效果更佳

## 提示

- 下方会显示 M（手动输入但不在分區树中的地点数）和 T（可在分區树中识别的地点数）
- 新增分区时如果名称与已有分区重复，系统会提示确认
