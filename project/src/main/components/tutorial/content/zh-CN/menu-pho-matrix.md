# 音系矩阵

查询单个或多个方言点的完整音系表，以矩阵形式展示声韵调拼合关系。

## 基本操作

![音系矩阵输入页面](/tutorial/menu-pho-matrix/input.jpg)

*音系矩阵输入页面*

1. 输入地点名称（可同时输入多个，最多 10 个）
2. 等待地点匹配完成
3. 点击「查询」

## 结果展示

![完整音系表](/tutorial/menu-pho-matrix/matrix.jpg)

*完整音系表——声韵调拼合矩阵*

- 以完整音系表形式展示，横行为声母、竖列为韵母，交叉格为音节
- 点击详情按钮可弹窗查看该方言点的详细信息
- 点击单元格可查看该音节的详细字例

## 文白读标注

支持文白读颜色标注（仅部分字表支持）：
- 红色：文读
- 蓝色：白读
- 紫色：同时为文白读
- 绿色：普通多音字（非文白读）

## 提示

- 支持全屏查看，尤其适用于移动端小屏幕
- 网地址同步匹配成功的地点名单，可直接分享链接
- 如需更灵活的分类方式（自选横纵轴和格内项目），使用「音素查询」
