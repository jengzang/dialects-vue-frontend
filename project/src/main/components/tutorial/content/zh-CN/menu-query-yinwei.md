# 查音位

分析音位的中古来源。与查中古的方向相反：查中古是「从中古条件出发找读音」，查音位是「从实际读音出发倒推中古来源」。

![输入页面总览](/tutorial/menu-query-yinwei/01-输入页面总览.webp)

## 输入页面

点击卡片选择要整理的维度（声母/韵母/声调等分类方式），然后输入待查音节（如 `a`、`h`、`ɐu`），再输入地点或分区。

![选择维度和输入音节](/tutorial/menu-query-yinwei/02-选择维度和输入音节.webp)

点击「运行」后等待结果。此功能计算复杂度较高，耗时较长，容易报错，可适当减少地点多尝试几次。

## 结果页面

结果页面按所选维度分组，展示该音位对应的中古来源分布。每个来源显示字数和占比。

![结果页面总览](/tutorial/menu-query-yinwei/03-结果页面总览.webp)

以下按钮均可以点击，与查中古的结果页面操作类似：

![结果各按钮标注](/tutorial/menu-query-yinwei/04-结果各按钮标注.webp)

点击各来源可弹窗细分查询。

![点击弹窗细分查询](/tutorial/menu-query-yinwei/05-点击弹窗细分查询.webp)

例如点击后查询该地点「假」摄字分别有哪些读音。

![点击查询假摄读音](/tutorial/menu-query-yinwei/06-点击查询假摄读音.webp)

![假摄各字读音结果](/tutorial/menu-query-yinwei/07-假摄各字读音结果.webp)

### 切换分类方式

可尝试不同分类方式查看音位来源。例如选择按「组」分类查询音节 a 的中古来源。

![按组分类查询](/tutorial/menu-query-yinwei/08-按组分类查询.webp)

![按组查询结果](/tutorial/menu-query-yinwei/09-按组查询结果.webp)

### 文白读颜色标注

查音位的结果也支持文白读颜色标注：
- 红色：文读
- 蓝色：白读
- 紫色：文白同形
- 绿色：纯多音字

![文白读颜色标注](/tutorial/menu-query-yinwei/14-文白读颜色标注.webp)

## 地图页面

同样会绘制在地图上，可直观查看某一读音的地理分布特征。

![地图页面](/tutorial/menu-query-yinwei/10-地图页面.webp)

点击地图上的点可查看详情。

![地图点击弹窗](/tutorial/menu-query-yinwei/11-地图点击弹窗.webp)

![地图弹窗详情](/tutorial/menu-query-yinwei/12-地图弹窗详情.webp)

也可以显示地名。

![地图显示地名](/tutorial/menu-query-yinwei/13-地图显示地名.webp)

## 常见用法示例

- 输入 `a`，分析音节 a 的中古来源（可能来自假摄、果摄、麻韵等）
- 输入 `h`，分析声母 h 的来源（可能来自晓母、溪母等）
- 按「组」分类查看：精组、见组等不同来源的占比

## 提示

- 此功能计算复杂度较高，地点太多时容易超时，建议先减少地点多试几次
- 与查中古的区别：查音位是从实际读音出发，适合做音类分合的探索性分析
- 如果只是想查看某个字的读音，用「查字」更直接
