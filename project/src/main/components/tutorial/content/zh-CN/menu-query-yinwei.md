# 查音位

分析特定音位（音值）的中古来源。与查中古的方向相反：查中古是「从中古条件出发找读音」，查音位是「从实际读音出发倒推中古来源」。

## 基本操作

1. 点击卡片选择要整理的维度（声母/韵母/声调等分类方式）
2. 输入待查的音节（如 `a`、`h`、`ɐu`）
3. 输入地点或分区
4. 点击「运行」

## 结果页面

- 按所选维度分组，展示该音位对应的中古来源分布
- 每个来源显示字数和占比
- 点击各来源可弹窗细分查询
- 点击地名可查看详情

## 地图页面

- 将音位来源的地理分布绘制在地图上
- 可直观查看某一读音的地理分布特征
- 点击地图上的点可弹窗查看详情

## 常见用法示例

- 输入 `a`，分析音节 a 的中古来源（可能来自假摄、果摄、麻韵等）
- 输入 `h`，分析声母 h 的来源（可能来自晓母、溪母等）
- 按「组」分类查看：精组、见组等不同来源的占比

## 提示

- 此功能计算复杂度较高，地点太多时容易超时，建议先减少地点多试几次
- 与查中古的区别：查音位是从实际读音出发，适合做音类分合的探索性分析
- 如果只是想查看某个字的读音，用「查字」更直接
