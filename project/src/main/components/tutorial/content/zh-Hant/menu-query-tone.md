# 查調

查詢方言點的聲調系統，以表格形式直觀展示調值、調類歸並情況。

## 基本操作

1. 輸入地點或分區（只需輸入地點，無需其他條件）
2. 點擊「運行」

## 結果頁面

- 以表格形式展示各方言點的調值
- 每行對應一個調類（陰平、陽平、陰上、陽上、陰去、陽去、陰入、陽入等）
- 單元格顯示具體調值（如 55、213、31 等）
- 可直觀看出調類的合併情況（如同一列多個相同調值表示合併）
- 點擊地名可彈窗查看詳細的調值資訊

## 地圖頁面

- 可切換不同調類在地圖上繪制
- 地圖上的數字是具體調值
- 如有調類合併情況，點擊彈窗顯示歸並詳情

## 特點

- 這是非常輕量的接口，響應速度較快
- 登入用戶可不受限制地同時查詢多個地點
- 適合快速對比多個方言點的聲調系統

## 提示

- 想看某兩個調類是否合併，可以直接在表格中對比兩行
- 地圖模式可直觀看出調值的區域分布特徵
- 如需深入比較調類合流情況，可使用「比較調類」功能
