# 查調

查詢方言點的聲調系統，以表格形式直觀展示調值、調類歸併情況。

## 基本操作

查調只需輸入地點或分區，無需其他條件。這是一個非常輕量的介面，響應速度較快。

![输入页面](/tutorial/menu-query-tone/01-输入页面.webp)

登入使用者可以不受限制地同時查詢多個地點。

![登录用户多地点查询](/tutorial/menu-query-tone/02-登录用户多地点查询.webp)

## 結果頁面

結果以表格形式呈現，可以直觀地看出調值、調類歸併的情況。每行對應一個調類（陰平、陽平、陰上、陽上、陰去、陽去、陰入、陽入等），單元格顯示具體調值（如 55、213、31 等）。同一列多個相同調值表示調類合併。

![结果表格调值调类](/tutorial/menu-query-tone/03-结果表格调值调类.webp)

點選地名後可檢視詳細的調值資訊。

![点击地名调值详情](/tutorial/menu-query-tone/04-点击地名调值详情.webp)

## 地圖頁面

結果也會繪製在地圖中，可切換不同調類進行繪製，地圖上繪製的是具體調值。

![地图模式切换调类](/tutorial/menu-query-tone/05-地图模式切换调类.webp)

如果有調類合併情況，點選後會彈窗顯示歸併情況。

![调类合并弹窗](/tutorial/menu-query-tone/06-调类合并弹窗.webp)

## 提示

- 想看某兩個調類是否合併，可以直接在表格中對比兩行
- 地圖模式可直觀看出調值的區域分佈特徵
- 如需深入比較調類合流情況，可使用「比較調類」功能
