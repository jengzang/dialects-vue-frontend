# 地圖繪制

在地圖上自由繪制標注，適合製作方言地圖或標注特定區域。

## 功能概述

- 在地圖上繪制點、線、面等標注
- 支持泰森多邊形（Voronoi）生成，可基於方言點繪制方言分布圖
- 標注數據可導出為 GeoJSON
- 地圖可導出為 PNG 圖片

## 基本操作

1. 選擇繪制工具（點/線/面等）
2. 在地圖上進行繪制
3. 編輯和管理繪制的圖層
4. 導出繪制結果

## 工作台

- 左側圖層列表管理所有繪制元素
- 支持圖層的顯示/隱藏、編輯、刪除
- 繪制狀態自動保存到本地存儲

## 導出功能

- 導出為 GeoJSON 格式，可導入 GIS 軟件
- 導出當前地圖為 PNG 圖片

## 提示

- 繪制的工作狀態會自動保存，刷新不丟失
- 此功能適合配合分區繪圖和查詢結果使用
