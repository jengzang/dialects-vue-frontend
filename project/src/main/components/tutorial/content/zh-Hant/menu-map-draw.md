# 地圖繪製

在地圖上自由繪製標註，適合製作方言地圖或標註特定區域。

## 功能概述

- 在地圖上繪製點、線、面等標註
- 支援泰森多邊形（Voronoi）生成，可基於方言點繪製方言分佈圖
- 標註資料可匯出為 GeoJSON
- 地圖可匯出為 PNG 圖片

## 基本操作

1. 選擇繪製工具（點/線/面等）
2. 在地圖上進行繪製
3. 編輯和管理繪製的圖層
4. 匯出繪製結果

## 工作臺

- 左側圖層列表管理所有繪製元素
- 支援圖層的顯示/隱藏、編輯、刪除
- 繪製狀態自動儲存到本地儲存

## 匯出功能

- 匯出為 GeoJSON 格式，可匯入 GIS 軟體
- 匯出當前地圖為 PNG 圖片

## 提示

- 繪製的工作狀態會自動儲存，重新整理不丟失
- 此功能適合配合分割槽繪圖和查詢結果使用
