# 音系矩陣

查詢單個或多個方言點的完整音系表，以矩陣形式展示聲韻調拼合關係。

## 基本操作

1. 輸入地點名稱（可同時輸入多個，最多 10 個）
2. 等待地點匹配完成
3. 點選「查詢」

## 結果展示

- 以完整音系表形式展示，橫行為聲母、豎列為韻母，交叉格為音節
- 點選詳情按鈕可彈窗檢視該方言點的詳細資訊
- 點選單元格可檢視該音節的詳細字例

## 文白讀標註

支援文白讀顏色標註（僅部分字表支援）：
- 紅色：文讀
- 藍色：白讀
- 紫色：同時為文白讀
- 綠色：普通多音字（非文白讀）

## 提示

- 支援全屏檢視，尤其適用於移動端小螢幕
- 網地址同步匹配成功的地點名單，可直接分享連結
- 如需更靈活的分類方式（自選橫縱軸和格內專案），使用「音素查詢」
