# 粵拼轉 IPA

批量將 Excel 文件中的粵拼（Jyutping）轉換為國際音標（IPA）。

## 基本操作

1. 登錄賬號
2. 在設置面板中調整轉換規則（可選，默認規則已涵蓋常見轉換）
3. 上傳 Excel 文件（.xlsx、.xls，單文件上限 3 MB）
4. 等待任務處理完成
5. 預覽結果並下載

## 自定義規則

- 可在設置面板中調整替換規則
- 規則按分類整理，方便檢查
- 可導出規則為 JSON 備份
- 可從 JSON 導入規則
- 重設會恢復為默認規則
- 規則保存到 localStorage，跨會話保持

## 輸出結果

- 預覽表顯示前 10 筆數據
- 字段包括：字、粵拼、IPA、聲母、韻母、音調
- 下載文件保留原始文件名並加前綴

## 提示

- 表中必須有「粵拼」列
- 導入規則後需手動點擊儲存才能持久化
- 文件格式不正確或過大時會直接報錯
