# 比較中古

將兩組中古條件進行對比，直接看它們在各地的讀音是否相近或差異明顯。

## 基本操作

![比較中古設置界面](/tutorial/menu-compare-zhonggu/setup.jpg)

*比較中古——加入條件到組1/組2*

1. 選擇比較維度：聲母、韻母或聲調
2. 在中央條件編輯區組出第一組中古條件
3. 點擊「加入組 1」
4. 修改條件，組出第二組條件
5. 點擊「加入組 2」
6. 輸入地點或分區，點擊「比較」

## 核心交互

- **中央區**是條件編輯區
- **組 1 / 組 2** 是待比較的條件集合
- 每次點擊「加入」是把當前條件做成快照存進對應組
- 修改中央條件不會自動更新已加入的項目

## 支持複雜條件

每組可加入多條條件。例如比較宕江分合情況：
- 組 1：宕攝字
- 組 2：江攝字
- 可同時加入多組條件進行綜合比較

## 相似度算法

![比較中古結果](/tutorial/menu-compare-zhonggu/result.jpg)

*比較中古地圖結果*

對於某個中古特徵，系統計算兩組在各地的讀音分布重疊度：

- 兩組中相同的讀音，取各自佔比的最小值，全部求和即為總相似度
- 重疊度 ≥ 閾值 → 綠色（高度一致）
- 中等重疊 → 黃色（部分相似）
- 低重疊 → 紅色（差異明顯）

同一地點內部比較時，該算法更為可靠（因為同一地點音值不同即意味著音類不同）。

## 提示

- 同一組內所有條件的「排除」設置必須一致
- 第一次使用建議每組只放一條條件，確認流程後再增加
- 想先單獨查看某組條件的結果，先用「查中古」各自查一遍
