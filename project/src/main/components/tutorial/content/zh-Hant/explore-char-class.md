# 漢字字集

按中古音韻地位逐級展開漢字，可查看各地位包含哪些漢字及廣韻注釋。

## 支持的字集（韻書）

- **中古廣韻**：最穩定，數據最全
- **上古音**
- **近古音**（洪武正韻等）
- **粵韻**

可在「關於 → 設置」中切換字集。

## 基本操作

![漢字字集樹狀結構](/tutorial/explore-char-class/overview.jpg)

*按中古音韻地位逐級展開漢字*

1. 系統預設停留在中古字表
2. 在左側選擇預設分組（如韻系、聲母、清濁等導向）
3. 根據需要增減層級或調整層級順序
4. 樹狀結構載入後，可在右側搜索節點
5. 可切換顯示/隱藏廣韻注釋

## 層級配置

可用層級包含：攝、呼、等、韻、入、調、清濁、系、組、母、部位、方式。

- 新增層級：自動加入尚未使用過的下一個欄位
- 調整層級：可改為其他欄位，也可上下移動順序
- 刪除層級：至少保留一層
- 層級配置會同步到網址，刷新後保留

## 交互

- 逐級展開樹狀結構，查看每層包含的漢字
- 搜索功能在已載入的樹上做前端查找
- 可按照聲紐、清濁等不同維度分類瀏覽

## 提示

- 切換字集後重新載入對應數據
- 廣韻注釋可以幫助理解各字的中古音韻地位
- 此頁面與「查中古」互補：這裡是瀏覽字表，查中古是按條件搜讀音
