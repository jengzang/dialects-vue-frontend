# 語保詞句

瀏覽和查詢中國語言資源保護工程（語保）的詞彙與語法例句數據，支持地圖、卡片、表格三種展示模式。

數據來源：共 1000 條詞彙數據，覆蓋 1247 個方言點（所有數據均來自語保官方平台，對登錄用戶公開）。

## 詞彙查詢

### 基本操作

1. 在輸入框搜索條目（支持繁簡匹配），從下拉建議中點選
2. 選擇展示模式：地圖、卡片或表格

### 地圖模式

- 比例尺較小時自動聚合顯示方言點
- 放大地圖後顯示具體內容
- 三種顯示方式：**釋義（文字）**、**語音（發音）**、**地名**
- 點擊地圖上的點可彈窗查看詳情
- 支持全屏顯示

### 卡片模式

- 卡片顯示地名、詞彙、注釋、發音、分區
- 搜索框可輸入地名/注釋/音標進行匹配
- 支持無限滾動加載

### 表格模式

- 所有列支持點擊排序
- 部分列支持彈窗篩選（多選、反選）
- 支持全屏查看
- 表格中可搜索匹配

## 語法查詢（語保 50 句）

切換到「語法」標籤頁，可查詢語保工程的 50 個語法例句：

- 同樣支持卡片、表格、地圖三種模式
- 卡片顯示地名、具體發音、注釋文字與分區
- 表格支持搜索、排序、篩選
- 地圖模式因句子較長，顯示可能不夠美觀但保留功能

## 提示

- 只輸入半個詞或自由輸入未在清單中的內容時表格不會出現
- 詞彙與語法各有自己的輸入框，切換標籤頁後需重新輸入
- 移動端做了專門適配，手機可正常使用
