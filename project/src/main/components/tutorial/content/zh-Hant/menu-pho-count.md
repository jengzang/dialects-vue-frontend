# 音節統計

統計多個地點的聲母、韻母、聲調出現頻率，支持圖表可視化分析。

## 基本操作

1. 輸入一批地點（最多 100 個）
2. 等待匹配完成後點擊「查詢」

## 結果展示

### 全量數據（預設）

- **餅圖**：查看各音節佔比，點擊可彈窗查看具體音節來源
- **柱狀圖**：查看各音節所存在的地點數，點擊可彈窗查看
- **散點圖**：橫軸為音節總數量，縱軸為地點數，圓圈越大代表音節數量越多
- 可切換只看聲母/韻母/聲調

### 自定義地點

可自由選擇地點進行分析：
- 匯總區域：按聲母、韻母、聲調順序顯示每個音節的統計資訊（總次數、出現地點數）
- 逐地點明細：每個地點的聲母、韻母、聲調數目
- 右側輪盤導航可快速跳轉到想查看的地點

## 交互

- 點擊圖表可彈窗查看詳情
- 輪盤導航支持自由滾動和快速定位
