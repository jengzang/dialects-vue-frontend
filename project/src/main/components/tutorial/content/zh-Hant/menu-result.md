# 結果頁

查詢和比較操作的結果展示頁面。本身不發起查詢，承接其他頁面的查詢引數並渲染結果。

![結果頁總覽](/tutorial/menu-result/01-overview.webp)

## 從這裡來

- **查字**：傳入漢字和地點，展示各地方言讀音
- **查中古**：傳入中古地位，展示符合條件字的各地讀音
- **查音位**：傳入音位的音值，展示中古來源分佈
- **查調**：傳入地點，展示調值調類表格

## 結果互動

### 點選與彈窗

- **點選地名**：彈窗檢視方言點詳細資訊
- **點選音值**：彈窗反查音節來源，支援同時查多個音節（不同地點也可）

![點選音值彈窗](/tutorial/menu-result/07-syllable-popup.webp)

- **點選左下角地點列表**：可滑動跳轉到對應地點，點選後滾動到目標位置
- **多音字**：會展示多個讀音

![多音字展示](/tutorial/menu-result/02-duoyin.webp)

### 細分查詢

- **點選地位**：可對當前結果的某個地位再次細分查詢

![點選地位細分](/tutorial/menu-result/05-status-click.webp)

- **多小窗並列**：支援開多個彈窗，不斷細分查詢，方便同時對比

![多小窗對比](/tutorial/menu-result/06-multi-window.webp)

### 統計與詳情

- **統計按鈕**：對當前結果按聲母/韻母/聲調再次細分查詢（如當前查韻母，點統計後可看聲母分佈）

![統計按鈕](/tutorial/menu-result/03-statistics.webp)

- **詳情按鈕**：檢視漢字的詳細音韻資訊

![詳情按鈕](/tutorial/menu-result/04-detail.webp)

### 篩選

- 支援按特定音值過濾資料，只保留想看的內容

## 顯示模式

點選右下按鈕切換展示密度：

- **全顯模式**：方框包著漢字，所有地位均顯示
- **主體模式**：僅一行展示漢字，自動篩掉佔比過低或字數過少的地位，更節省空間

![顯示模式切換](/tutorial/menu-result/08-display-mode.webp)

## 文白讀標記

部分字表支援文白讀顏色標記：

- **紅色**：文讀
- **藍色**：白讀
- **紫色**：文白讀共用此聲/韻/調
- **綠色**：純粹的多音字，非文白讀

![文白讀顏色標記](/tutorial/menu-result/09-wenbai.webp)

查字結果中：藍色白讀、紅色文讀、黑色普通漢字。

## 載入狀態

- 載入過程中顯示計時器
- 超過 30 秒出現長等待提醒，說明查詢範圍較大

## 提示

- 結果頁依賴前一步查詢資料，沒有傳入引數時不會有結果
- 如果結果方向不對，回原查詢頁改條件；方向對了再去地圖頁看空間分佈
