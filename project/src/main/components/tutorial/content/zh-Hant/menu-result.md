# 結果頁

查詢和比較操作的結果展示頁面。本身不發起查詢，而是承接其他頁面的查詢參數並渲染結果。

## 從哪裡來

- **查字**（tab1）：傳入漢字和地點，展示各地方言讀音
- **查中古**（tab2）：傳入中古條件，展示符合條件字的各地讀音
- **查音位**（tab3）：傳入音位值，展示中古來源分布
- **查調**（tab4）：傳入地點，展示調值調類表格

不同來源模式展示不同的結果組件：
- 查字與查調走 `CharsAndTones` 類型畫面
- 查中古與查音位走 `ResultList` 類型畫面

## 結果交互

- 點擊地名彈窗查看方言點詳細資訊
- 點擊音值彈窗反查音節來源
- 篩選功能按特定音值過濾數據
- 統計按鈕按聲母/韻母/聲調細分查詢
- 詳情按鈕查看漢字的詳細音韻資訊

## 切換標籤

結果頁頂部有標籤可切換：
- **表格結果**：以表格形式展示
- **地圖結果**：在地圖上展示空間分布

## 載入狀態

- 載入過程中顯示計時器
- 超過 30 秒出現長等待提醒，說明查詢範圍較大

## 提示

- 結果頁依賴 `globalPayload`，沒有前一步查詢數據時不會有結果
- 如果結果方向不對，回原查詢頁改條件；方向對了再去地圖頁看空間分布
