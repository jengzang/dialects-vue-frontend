# Praat · 分析結果

查看聲學分析的詳細結果，包括基頻、強度、共振峰、頻譜圖等。

## 結果內容

![Praat 分析結果](/tutorial/explore-praat-results/results.jpg)

*聲學分析結果——基頻、強度、共振峰*

根據勾選的分析模塊，結果頁面會展示：

- **基本資訊**：時長、採樣率
- **基頻分析**：調值特徵、五度標調計算、基頻曲線。黃色部分為韻核
- **強度分析**：平均強度（dB）、強度範圍、強度軌跡圖
- **共振峰分析**：共振峰軌跡，反映元音音值
- **音質分析**：諧噪比（HNR）、基頻微擾（jitter）、振幅微擾（shimmer）
- **音段分析**：單音節模式拆分為 rime_core（韻核）和 syllable_like；連續語流拆分為 voiced、speech、silence
- **頻譜圖**：頻率-時間二維能量分布。僅支持 3 秒以內語音，需手動點擊載入

## 五度標調

後端自動計算調值波動。例如 `3.67-1.7-1.18-1.04-1.85`，表示先降後微升的調型。

## 圖表交互

- 所有圖表支持拖動、縮放
- 可查看每個數據點的具體數值

## 任務流程

1. 點擊「開始分析」後上傳音頻並建立分析任務
2. 自動輪詢任務狀態，顯示進度
3. 任務完成後自動載入完整結果
4. 離開頁面時自動取消未完成的任務

## 提示

- 沒有登入時會先跳轉到登入頁面
- 如果某個模塊沒有數據，對應的卡片和圖表不會顯示
