# 查字

輸入漢字和地點，查看該字在不同方言點的具體讀音。

## 基本操作

1. 在輸入框中鍵入要查詢的漢字（支持繁簡）
2. 在下方地點/分區區域選擇方言點或分區
3. 點擊「運行」按鈕，自動跳轉到結果頁面

## 結果頁面

- 每個方言點顯示該漢字的具體讀音（IPA）
- 多音字會展示多個讀音
- 顏色標注文白讀：紅色為文讀、藍色為白讀、黑色為普通讀音
- 點擊地名可彈窗查看該方言點的詳細資訊
- 點擊音值可反查音節來源

## 地圖頁面

切換到地圖標籤頁後：

- 地圖上每個點顯示該漢字在該地的最常見讀音
- 點擊地圖上的點可彈窗查看詳情
- 右上角可切換顯示地名標籤
- 地圖支持全屏展示，方便截圖
- 可切換不同底圖（街道圖、地形圖等）

## 篩選與統計

在結果頁面中：
- 可篩選特定音值，只顯示匹配的數據
- 點擊統計按鈕可按聲母/韻母/聲調細分查詢
- 點擊詳情按鈕可查看漢字的詳細音韻資訊

## 提示

- 一次可查詢多個漢字
- 地點支持模糊匹配，輸入簡繁均可
- 輸入行政區劃名稱可匹配該區域所有方言點
- 與查中古不同：查字以漢字為出發點，直接看讀音
