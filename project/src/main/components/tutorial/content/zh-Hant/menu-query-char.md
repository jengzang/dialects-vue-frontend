# 查字

輸入漢字和地點，檢視該字在不同方言點的具體讀音。

![输入页面](/tutorial/menu-query-char/01-输入页面.webp)

## 基本操作

1. 在輸入框中鍵入要查詢的漢字（支援繁簡）
2. 在下方地點/分區區域選擇方言點或分區
3. 點選「執行」按鈕，自動跳轉到結果頁面

![输入汉字和地点](/tutorial/menu-query-char/02-输入汉字和地点.webp)

## 結果頁面

點選執行後自動跳轉到結果頁面，即可檢視漢字的詳細讀音。每個方言點顯示該漢字的具體讀音（IPA），多音字會展示多個讀音。

![结果页面读音](/tutorial/menu-query-char/03-结果页面读音.webp)

### 文白讀顏色標註

部分字表支援文白讀顏色標註：
- 紅色：文讀
- 藍色：白讀
- 黑色：普通讀音

![文白读颜色标注](/tutorial/menu-query-char/04-文白读颜色标注.webp)

## 地圖頁面

切換到地圖頁面，可看到讀音的地理分佈。地圖上每個點顯示該漢字在該地的最常見讀音。

![地图读音地理分布](/tutorial/menu-query-char/05-地图读音地理分布.webp)

點選地圖上的點可彈窗檢視註釋詳情。

![地图点击查看注释](/tutorial/menu-query-char/06-地图点击查看注释.webp)

也可開啟「檢視地名」開關顯示各地名稱。

![地图显示地名](/tutorial/menu-query-char/07-地图显示地名.webp)

## 提示

- 一次可查詢多個漢字
- 地點支援模糊匹配，輸入簡繁均可
- 輸入行政區劃名稱可匹配該區域所有方言點
- 與查中古不同：查字以漢字為出發點，直接看讀音；與查音位不同：查音位是從讀音倒推來源
