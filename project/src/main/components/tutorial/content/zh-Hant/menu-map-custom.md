# 自定地圖

管理自己的自定義方言特徵數據，並將其繪制到地圖上。用戶的自定義數據僅本人可見，與帳號綁定。

## 補充自定義數據

![自定地圖面板](/tutorial/menu-map-custom/overview.jpg)

*添加自定義數據面板*

適用於補充檔案中缺少的方言點或特徵數據。例如檔案里的東莞方言點數據有限，可自己補充。

### 添加流程

1. 填入地點簡稱
2. 如果地點存在於檔案里會自動匹配分區；否則需手動填寫分區。推薦分區與音典檔案保持一致，方便後續搜索
3. 坐標：點擊地圖自動填入
4. 類別和當前查詢特徵：根據頁面自動識別
5. 值：顯示在地圖上的值
6. 說明（可選）：在地圖上點擊自定義地點時彈窗顯示

## 管理數據

在自定義頁面可：
- 按調查點整理個人數據，針對單個方言點不斷補充
- 按方言特徵整理，針對某一待比較特徵不斷補充方言點
- 點擊卡片後單獨繪制自定義數據

## 數據入口

- **逐條新增**：跳轉到地圖頁並自動打開填寫面板
- **批量新增**：跳轉到個人數據管理頁（`/auth/data`）

## 搜索特徵

登入後可在搜索框中搜索已有特徵名稱，選中後點擊查詢跳到地圖頁查看。

## 提示

- 需登入才能使用
- 按查詢後會自動跳轉到地圖頁顯示
- 幫助按鈕內有欄位說明和格式示例
