# 自定地圖

管理自己的自定義方言特徵資料，並將其繪製到地圖上。使用者的自定義資料僅本人可見，與賬號繫結。

## 補充自定義資料

適用於補充檔案中缺少的方言點或特徵資料。例如檔案裡的東莞方言點資料有限，可自己補充。

### 新增流程

1. 填入地點簡稱
2. 如果地點存在於檔案裡會自動匹配分割槽；否則需手動填寫分割槽。推薦分割槽與音典檔案保持一致，方便後續搜尋
3. 座標：點選地圖自動填入
4. 類別和當前查詢特徵：根據頁面自動識別
5. 值：顯示在地圖上的值
6. 說明（可選）：在地圖上點選自定義地點時彈窗顯示

## 管理資料

在自定義頁面可：
- 按調查點整理個人資料，針對單個方言點不斷補充
- 按方言特徵整理，針對某一待比較特徵不斷補充方言點
- 點選卡片後單獨繪製自定義資料

## 資料入口

- **逐條新增**：跳轉到地圖頁並自動開啟填寫面板
- **批次新增**：跳轉到個人資料管理頁（`/auth/data`）

## 搜尋特徵

登入後可在搜尋框中搜索已有特徵名稱，選中後點擊查詢跳到地圖頁檢視。

## 提示

- 需登入才能使用
- 按查詢後會自動跳轉到地圖頁顯示
- 幫助按鈕內有欄位說明和格式示例
