# 演化

檢視單個方言點在不同音韻分類維度下的演變分佈，支援餅圖和桑基圖（Sankey）。

## 基本操作

1. 登入賬號（需登入才能使用）
2. 選擇統計模式和字表
3. 選擇第一層分類和第二層分類（不能選同一欄）
4. 輸入 1 個地點
5. 點選「查詢」
![演化1.webp](/tutorial/menu-pho-evolution/演化1.webp)

## 結果展示

- 查詢成功後出現「聲母、韻母、聲調」三個切換按鈕
- **餅圖**：展示當前分類下的音變分佈
![演化2.webp](/tutorial/menu-pho-evolution/演化2.webp)
- **桑基圖（Sankey）**：展示音變流向，可切換顯示
![演化3.webp](/tutorial/menu-pho-evolution/演化3.webp)
- 桌面端：滑鼠懸停或點選餅圖可顯示細節卡片
- 手機端：以可關閉的卡片方式顯示

## 示例資料

進入頁面時會先載入示例資料，讓你在查詢前瞭解功能效果。真實查詢後示例才會被結果替換。

## 提示

- 每次只能查 1 個地點
- 第一層與第二層分類必須都選，且不能相同
- 適合研究單個方言點的歷史音變趨勢
