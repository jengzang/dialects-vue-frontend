# 演化

查看单个方言点在不同音韵分类维度下的演变分布，支持饼图和桑基图（Sankey）。

## 基本操作

1. 登录账号（需登录才能使用）
2. 选择统计模式和字表
3. 选择第一层分类和第二层分类（不能选同一栏）
4. 输入 1 个地点
5. 点击「查询」

## 结果展示

- 查询成功后出现「声母、韵母、声调」三个切换按钮
- **饼图**：展示当前分类下的音变分布
- **桑基图（Sankey）**：展示音变流向，可切换显示
- 桌面端：鼠标悬停或点击饼图可显示细节卡片
- 手机端：以可关闭的卡片方式显示

## 示例数据

进入页面时会先载入示例数据，让你在查询前了解功能效果。真实查询后示例才会被结果替换。

## 提示

- 每次只能查 1 个地点
- 第一层与第二层分类必须都选，且不能相同
- 适合研究单个方言点的历史音变趋势
