# 登錄

使用郵箱或用戶名登錄方音圖鑑。任何人都可免費註冊。

## 登錄方式

支持兩種登錄方式，可點擊切換：
- **郵箱登錄**：郵箱 + 密碼
- **用戶名登錄**：用戶名 + 密碼

## 基本操作

1. 選擇登錄方式
2. 輸入對應的賬號和密碼
3. 點擊登錄

## 登錄後

- 如果是從受保護頁面被導來的（如 Praat 分析），登錄成功後會回到原頁面
- 否則自動刷新頁面，同步登錄狀態
- 可使用個人數據存儲、自定義數據等需登錄的功能

## 沒有賬號？

點擊底部的「沒有賬號？」鏈接可切換到註冊頁面。註冊只需郵箱 + 密碼 + 用戶名。

## 提示

- 切換登錄方式時密碼欄會被清空（設計如此）
- 密碼至少需要 6 位
- 賬號/密碼錯誤時會顯示登錄失敗提示
