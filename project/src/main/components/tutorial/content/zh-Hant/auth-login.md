# 登入

使用郵箱或用戶名登入方音圖鑑。任何人都可免費註冊。

## 登入方式

支持兩種登入方式，可點擊切換：
- **郵箱登入**：郵箱 + 密碼
- **用戶名登入**：用戶名 + 密碼

## 基本操作

1. 選擇登入方式
2. 輸入對應的帳號和密碼
3. 點擊登入

## 登入後

- 如果是從受保護頁面被導來的（如 Praat 分析），登入成功後會回到原頁面
- 否則自動刷新頁面，同步登入狀態
- 可使用個人數據儲存、自定義數據等需登入的功能

## 沒有帳號？

點擊底部的「沒有帳號？」連結可切換到註冊頁面。註冊只需郵箱 + 密碼 + 用戶名。

## 提示

- 切換登入方式時密碼欄會被清空（設計如此）
- 密碼至少需要 6 位
- 帳號/密碼錯誤時會顯示登入失敗提示
