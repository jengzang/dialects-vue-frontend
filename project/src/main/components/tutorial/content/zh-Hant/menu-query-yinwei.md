# 查音位

分析特定音位（音值）的中古來源。與查中古的方向相反：查中古是「從中古條件出發找讀音」，查音位是「從實際讀音出發倒推中古來源」。

## 基本操作

![查音位輸入頁面](/tutorial/menu-query-yinwei/input.jpg)

*查音位輸入頁面*

1. 點擊卡片選擇要整理的維度（聲母/韻母/聲調等分類方式）
2. 輸入待查的音節（如 `a`、`h`、`ɐu`）
3. 輸入地點或分區
4. 點擊「運行」

## 結果頁面

- 按所選維度分組，展示該音位對應的中古來源分布
- 每個來源顯示字數和佔比
- 點擊各來源可彈窗細分查詢
- 點擊地名可查看詳情

## 地圖頁面

- 將音位來源的地理分布繪制在地圖上
- 可直觀查看某一讀音的地理分布特徵
- 點擊地圖上的點可彈窗查看詳情

## 常見用法示例

- 輸入 `a`，分析音節 a 的中古來源（可能來自假攝、果攝、麻韻等）
- 輸入 `h`，分析聲母 h 的來源（可能來自曉母、溪母等）
- 按「組」分類查看：精組、見組等不同來源的佔比

## 提示

- 此功能計算複雜度較高，地點太多時容易超時，建議先減少地點多試幾次
- 與查中古的區別：查音位是從實際讀音出發，適合做音類分合的探索性分析
- 如果只是想查看某個字的讀音，用「查字」更直接
