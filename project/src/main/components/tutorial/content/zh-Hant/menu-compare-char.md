# 比較漢字

比較兩個漢字在不同方言點的讀音異同。透過顏色直觀展示各地讀音的相同/部分相同/完全不同。

## 基本操作

![比較漢字輸入界面](/tutorial/menu-compare-char/01-overview.jpg)

![地圖結果——顏色區分相同/部分相同/不同](/tutorial/menu-compare-char/02-map.jpg)

![點擊地圖查看具體讀音細節](/tutorial/menu-compare-char/03-popup.jpg)


1. 分別在組 1 和組 2 的輸入框中各輸入一個漢字
2. 選擇比較角度：聲母、韻母或聲調
3. 輸入地點或分區
4. 點擊「比較」，直接跳轉到地圖頁面

## 結果解讀

地圖上以顏色區分比較結果：

- **綠色**：兩個字的讀音完全相同
- **黃色**：部分相同
- **紅色**：完全不同
- 灰色：無數據

## 典型用例

- 「心」與「時」的聲母比較，可大致看出粵方言的邊擦音分布
- 「客」與「黑」的調值比較，可大致看出粵方言的陰入情況
- 「九」與「酒」的聲母比較，可看出南方方言的顎化情況

## 結果交互

- 點擊地圖上的點可彈窗查看具體讀音細節
- 支持全屏放大查看
- 可切換顯示地名標籤

## 提示

- 兩個輸入框各只保留 1 個有效字
- 必須先選擇比較角度（聲母/韻母/聲調）才能運行
- 如果只想知道某個字本身怎麼讀，先用「查字」
