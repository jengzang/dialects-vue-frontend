# 查中古

按中古音韻地位整理各方言點的讀音。系統會根據所選的中古條件，去資料庫中找出符合條件的字，再展示這些字在不同地點的讀音。

## 基本操作

1. 選擇分析維度：聲母、韻母或聲調
2. 選擇中古地位條件，可從攝、韻、等、呼、清濁、系、組、母、舒入、調、部位、方式共 12 種類型中選擇
3. 選擇多種條件時，系統自動計算笛卡爾積（所有選項相互組合）
4. 點選「詳情」可檢視所選地位組合具體包含哪些字
5. 輸入地點或分割槽，點選「執行」

## 結果頁面

- 按中古地位分組展示各地方言讀音
- 多音字展示多個讀音
- 支援文白讀顏色標註：紅色文讀、藍色白讀、紫色文白同形、綠色純多音字
- 點選音值可彈窗反查音節來源
- 點選地名可檢視方言點詳細資訊
- 左側地點列表可快速跳轉

## 篩選與細分查詢

- 篩選功能可按特定音值過濾資料
- 點選「統計」會再次細分查詢（如查韻母后統計聲母、聲調分佈）
- 點選地位標籤可繼續細分查詢
- 可開啟多個小窗，並行對比不同條件的結果

## 切換顯示模式

右下角按鈕可切換：
- **全顯模式**：方框包著漢字，顯示所有地位
- **主體模式**：只顯示一行漢字，篩掉佔比過低或字數過少的地位，更節省空間

## 地圖頁面

- 預設顯示佔比最高的音值
  - 大於 50%：直接顯示
  - 35%~50%：帶括號
  - 20%~35%：帶括號和星號（*）
  - 小於 20%：不顯示
- 點選地圖上的點可彈窗檢視詳情

## 提示

- 首次使用建議只選 1-2 個核心條件，結果更容易看懂
- 結果太多時先加分割槽縮小範圍；結果太少時減少條件數量
- 按鈕灰色時通常表示中古條件尚未形成有效查詢
- 想從字形出發查讀音用「查字」；想從音值倒推中古來源用「查音位」
