# 詞表展示

瀏覽和搜尋所有協作者提交的詞表資料，支援卡片、地圖、表格三種展示模式。無需登入即可瀏覽全部資料。

![詞表首頁總覽](/tutorial/menu-vocabulary/01-词表首页总览.webp)

## 搜尋與篩選

頂部的輸入框是詞表展示的核心入口。輸入關鍵詞後，可以同時搜尋標準詞、方言詞、音標、詳細釋義等欄位，系統會自動匹配相關詞條。

![詞表展示輸入頁面](/tutorial/menu-vocabulary/36-词表展示输入页面.webp)

在下拉選單中可以選擇限定搜尋範圍，例如只搜尋標準詞或只搜尋方言詞：

![按欄位篩選](/tutorial/menu-vocabulary/37-按字段筛选.webp)

點選輸入框旁的齒輪圖示，可以開啟搜尋配置面板，調整搜尋匹配方式（如精確匹配或模糊匹配）：

![搜尋配置齒輪](/tutorial/menu-vocabulary/38-搜索配置齿轮.webp)

除了關鍵詞搜尋，還可以按地點篩選資料，檢視某個方言點的所有詞條：

![按地點篩選](/tutorial/menu-vocabulary/39-按地点筛选.webp)

同時支援按行政區劃篩選，方便批次檢視同一區域下多個地點的詞表資料。

## 卡片模式

預設展示模式。每條詞條以卡片形式呈現，直觀展示完整資訊：

- **標準詞**：通用說法
- **方言詞**：當地方言的說法
- **音標**：方言詞的實際發音
- **詳細釋義**：補充說明、例句或使用場景

![卡片模式瀏覽](/tutorial/menu-vocabulary/40-卡片模式浏览.webp)

卡片每頁載入 50 條資料，滾動到底部後點擊「載入更多」可繼續瀏覽：

![卡片載入更多](/tutorial/menu-vocabulary/41-卡片加载更多.webp)

## 地圖模式

切換到地圖模式後，初始狀態在地圖上展示所有地點的詞條數目分佈，可以直觀看到哪些地區詞表資料更豐富。

![地圖初始化展示](/tutorial/menu-vocabulary/42-地图初始化展示.webp)

可以像卡片模式一樣在搜尋框中輸入關鍵詞，也可以按標準詞篩選地圖上的資料。在左側選框中選中某個標準詞後：

![按標準詞篩選地圖](/tutorial/menu-vocabulary/43-按标准词筛选地图.webp)

系統會自動繪製地圖，以圓點標註各地對該標準詞的方言說法：

![篩選後自動繪圖](/tutorial/menu-vocabulary/44-筛选后自动绘图.webp)

地圖支援切換多種顯示方式，可以從不同維度觀察詞表資料的地理分佈：

- **按方言詞顯示**：地圖上直接展示各地的方言詞說法
- **按音標顯示**：展示各地的實際讀音
- **按地點顯示**：僅展示地點名稱

![切換顯示方式](/tutorial/menu-vocabulary/45-切换显示方式.webp)

![地圖顯示方式切換](/tutorial/menu-vocabulary/46-地图显示方式切换.webp)

## 表格模式

表格模式以列表形式展示所有資料，與管理表格不同，這裡展示的是全部資料，任何人都能檢視，但不能編輯。

![表格展示模式](/tutorial/menu-vocabulary/47-表格展示模式.webp)

同樣支援搜尋、按列篩選、升序/降序排序等操作，方便快速定位感興趣的資料。

## 提示

- 詞表展示頁面無需登入即可瀏覽全部資料
- 如果資料量大，善用地點篩選和行政區域篩選縮小範圍
- 地圖模式下選中標準詞後，可以切換不同顯示方式來對比空間分佈
- 想要貢獻或編輯詞表，請切換到「匯入詞表」或「管理詞表」標籤
