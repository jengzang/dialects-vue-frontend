# 分區繪圖

將方言點或分區直接繪製成點位地圖，支持分區著色展示地理分布。

## 基本操作

1. 輸入地點名稱，或從分區選擇器勾選分區
2. 選擇顯示的分區層級（一級/二級/三級，地圖集和音典分區各有三級）
3. 點擊執行，自動跳轉到地圖頁

## 分區著色

- 不同分區以不同顏色標示，直觀展示地理分布
- 滑鼠懸浮或單擊可查詢具體地點名和分區資訊

## 全部數據

勾選「使用全部數據」可一次性繪制全國分區圖：
- 使用的是專門優化的新接口，響應更快
- 數據量大時可能較卡

## 典型用例

- 按二級分區繪制音典嶺南、嶺西分區
- 地圖集一級分區
- 音典一級分區
- 全國範圍的方言分區對比

## 提示

- 結果會直接跳轉到地圖頁展示，不留在本頁
- 注意分區的模式（地圖集 vs 音典），畫出來的範圍可能不同
