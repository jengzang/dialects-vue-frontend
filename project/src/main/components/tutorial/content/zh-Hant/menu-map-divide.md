# 分割槽繪圖

將方言點或分割槽直接繪製成點位地圖，支援分割槽著色展示地理分佈。

## 基本操作

1. 輸入地點名稱，或從分割槽選擇器勾選分割槽
2. 選擇顯示的分割槽層級（一級/二級/三級，地圖集和音典分割槽各有三級）
3. 點選執行，自動跳轉到地圖頁

## 分割槽著色

- 不同分割槽以不同顏色標示，直觀展示地理分佈
- 滑鼠懸浮或單擊可查詢具體地點名和分割槽資訊

## 全部資料

勾選「使用全部資料」可一次性繪製全國分割槽圖：
- 使用的是專門最佳化的新介面，響應更快
- 資料量大時可能較卡

## 典型用例

- 按二級分割槽繪製音典嶺南、嶺西分割槽
- 地圖集一級分割槽
- 音典一級分割槽
- 全國範圍的方言分割槽對比

## 提示

- 結果會直接跳轉到地圖頁展示，不留在本頁
- 注意分割槽的模式（地圖集 vs 音典），畫出來的範圍可能不同
