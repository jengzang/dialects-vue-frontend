# 分割槽繪圖

將方言點或分割槽直接繪製成點位地圖，支援分割槽著色展示地理分佈。

![分割槽繪圖概覽](/tutorial/menu-map-divide/01-overview.webp)

## 基本操作

1. 輸入地點名稱，或從分割槽選擇器勾選分割槽
2. 選擇顯示的分割槽層級

地圖集和音典分割槽都有三級，可以選擇用於繪圖的層級數：

![選擇分割槽層級](/tutorial/menu-map-divide/04-select-level.webp)

輸入地點或選擇分割槽後，點選執行自動跳轉到地圖頁：

![分割槽繪圖輸入介面](/tutorial/menu-map-divide/03-input.webp)

## 分割槽著色

不同分割槽以不同顏色標示，直觀展示地理分佈。比如按照二級分割槽繪製音典嶺南、嶺西分割槽：

![二級分割槽示例——音典嶺南嶺西](/tutorial/menu-map-divide/05-level2-example.webp)

![不同分割槽以不同顏色標示](/tutorial/menu-map-divide/06-colors.webp)

滑鼠移至上方或單擊，可查詢具體地點名和分割槽資訊：

![懸停查詢地點名和分割槽](/tutorial/menu-map-divide/07-hover-detail.webp)

## 全部資料

勾選「使用全部資料」可一次性繪製全國分割槽圖。使用專門最佳化的新介面，但資料量大時可能較卡：

![全國分割槽圖——音典一級分割槽](/tutorial/menu-map-divide/02-national.webp)

![使用全部資料繪製全國](/tutorial/menu-map-divide/08-all-data.webp)

地圖集一級分割槽效果：

![地圖集一級分割槽](/tutorial/menu-map-divide/09-atlas-level1.webp)

## 提示

- 結果會直接跳轉到地圖頁展示
- 注意分割槽的模式（地圖集 vs 音典），畫出來的範圍可能不同
