# 上傳音訊

Praat 聲學分析的入口。上傳語音檔案或直接錄音，擷取分段後開始分析。

## 功能簡介

網站集成了 Praat 核心演算法（基於 `praat-parselmouth` Python 包），提供現代化的網頁介面進行聲學分析。相比桌面版 Praat，操作更為簡便，移動端和桌面端均可使用。

**需要登入**才能使用（因 Praat 演算法非常消耗 CPU，伺服器效能有限）。

## 上傳語音

- 拖動檔案或點選「選擇檔案」上傳
- 支援 WAV、MP3、M4A、WebM、OGG、FLAC、AAC 等多種格式，無需預先轉換
- 也可以直接在網站上錄音，無需預先準備檔案

![拖拽檔案上傳彈窗](/tutorial/explore-praat-upload/02-upload-dialog.webp)

手機錄音音質通常好於電腦自帶麥克風，推薦使用手機錄製後上傳：

![手機錄音介面](/tutorial/explore-praat-upload/05-mobile-record.webp)

## 擷取分段

上傳後可在波形預覽區拖動擷取分段：

![波形圖擷取分段](/tutorial/explore-praat-upload/03-waveform-segment.webp)

- **自動模式**：系統自動切段，可在多段間切換選擇
- **手動模式**：在波形上拖動選取區間（僅單段原音且總長不超過 10 秒時可用）
- 手動區段全部清空後會自動回到原始片段集合
- 只有當前選中的片段會進入分析

對於需要精確分析元音的情況，應當使用單音節模式，仔細擷取語音部分並確認無雜音：

![單音節模式精確擷取](/tutorial/explore-praat-upload/04-single-syllable.webp)

## 分析模式

- **單音節模式**：擷取一個具體音節，分析最精確。適合元音分析和精確基頻定調
- **連續語流模式**：上傳一段語流，後端自動分段。適合基頻定調，可一次上傳多個調類；但用於元音空間分析時誤差較大

## 分析設定

![七個分析模組詳情](/tutorial/explore-praat-upload/07-analysis-modules.webp)

- **分析模組**（共七種）：基本資訊、基頻分析、強度分析、共振峰分析、音質分析、音段分析、頻譜圖分析
- **基本資訊**：音訊時長、取樣率
- **基頻分析**：調值特徵、五度標調計算、基頻曲線——基頻定調依賴此模組
- **強度分析**：平均強度（dB）、強度範圍、強度軌跡
- **共振峰分析**：共振峰軌跡——元音空間依賴此模組
- **音質分析**：諧噪比（HNR）、基頻微擾（jitter）、振幅微擾（shimmer）
- **音段分析**：單音節模式拆分為 rime_core（韻核）和 syllable_like；連續語流拆分為 voiced、speech、silence
- **頻譜圖分析**：頻率-時間二維能量分佈，僅支援 3 秒以內語音
- **解析度**：快速、標準、高精度三種模式

完成後點選開始分析，上傳較慢請耐心等待。
