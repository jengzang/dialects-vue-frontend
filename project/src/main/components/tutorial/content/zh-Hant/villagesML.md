# 村名機器學習

使用機器學習方法分析自然村名的模式和規律。

## 功能模組

- **村名搜尋**：按關鍵詞、區域搜尋村名，檢視詳細資訊與深度分析報告
- **字頻分析**：分析村名中字元的使用頻率、區域傾向性、語義嵌入向量與統計顯著性
- **語義分析**：探索村名的語義類別、標籤組合模式、語義網路關係與語義組成結構
- **空間分析**：視覺化村名的地理分佈、識別空間熱點聚類、分析空間整合模式
- **模式分析**：提取N-gram模式、分析結構規律、發現村名命名的語言學特徵
- **區域分析**：計算區域聚合統計、生成區域特徵向量、進行跨區域比較分析
- **ML計算**：執行機器學習聚類分析、提取高維特徵向量、進行子集深度分析（需登入）
- **系統資訊**：檢視資料庫概覽、表統計資訊、系統執行狀態與快取管理

## 使用方式

1. 在導航中選擇功能模組
2. 根據需要切換子標籤頁
3. 檢視分析結果和視覺化圖表

## 提示

- 此功能為獨立單頁應用（SPA），通過 `/villagesML` 路由載入
- 目前覆蓋廣東自然村資料，後續可能擴充套件至全國
