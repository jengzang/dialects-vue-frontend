# 村名機器學習

使用機器學習方法分析自然村名的模式和規律。

## 功能模塊

- **搜索**（module=search）：搜索和瀏覽村名數據
- **字頻分析**（module=character）：分析村名中漢字的出現頻率、嵌入（embeddings）、網絡關係（network）、顯著性（significance）
- **語義分析**（module=semantic）：按語義類別分析村名的分類規律

## 使用方式

1. 在導航中選擇功能模塊
2. 根據需要切換子標籤頁
3. 查看分析結果和可視化圖表

## 提示

- 此功能為獨立單頁應用（SPA），通過 `/villagesML` 路由加載
- 目前覆蓋廣東自然村數據，後續可能擴展至全國
