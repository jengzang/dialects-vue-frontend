# 廣東自然村表格

以表格形式瀏覽和查詢廣東自然村資料，支援排序、篩選、分頁。

## 欄位

共 8 欄：市級、區縣級、鄉鎮級、行政村、自然村、方言分佈、longitude、latitude。

其中可開啟篩選器的欄位：市級、區縣級、鄉鎮級、行政村、方言分佈。

![自然村表格1.webp](/tutorial/explore-villages-table/自然村表格1.webp)

## 搜尋

- 搜尋框對全部欄位進行後端查詢
- 輸入後自動搜尋
- 每次搜尋頁碼回到第 1 頁
![自然村表格3.webp](/tutorial/explore-villages-table/自然村表格3.webp)

## 排序

每欄表頭支援升序（▲）和降序（▼），點選後立即重新查詢。

## 篩選

- 篩選器選項根據當前搜尋條件動態變化
- 支援多選、全選/反選
- 套用篩選後頁碼回到第 1 頁
![自然村表格2.webp](/tutorial/explore-villages-table/自然村表格2.webp)

## 分頁

- 每頁 50 筆
- 支援上下頁翻頁和直接輸入頁碼跳轉

## 全屏

右下角全屏按鈕適合檢視寬表格，切換後搜尋/排序/篩選狀態保持不變。

## 管理員功能

管理員額外可見：匯出 Excel、新增/編輯/刪除資料、批次替換等功能。

## 提示

- 搜尋為後端查詢，結果不立即變化是因為防抖延遲
- 篩選器選項受當前搜尋條件影響，不一定是全表完整值
