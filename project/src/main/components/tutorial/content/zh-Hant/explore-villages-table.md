# 廣東自然村表格

以表格形式瀏覽和查詢廣東自然村數據，支持排序、篩選、分頁。

## 欄位

共 8 欄：市級、區縣級、鄉鎮級、行政村、自然村、方言分布、longitude、latitude。

其中可打開篩選器的欄位：市級、區縣級、鄉鎮級、行政村、方言分布。

## 搜索

- 搜索框對全部欄位進行後端查詢
- 輸入後約 300ms 延遲自動搜索
- 每次搜索頁碼回到第 1 頁

## 排序

每欄表頭支持升序（▲）和降序（▼），點擊後立即重新查詢。

## 篩選

- 篩選器選項根據當前搜索條件動態變化
- 支持多選、全選/反選
- 套用篩選後頁碼回到第 1 頁

## 分頁

- 每頁 50 筆
- 支持上下頁翻頁和直接輸入頁碼跳轉

## 全屏

右下角全屏按鈕適合查看寬表格，切換後搜索/排序/篩選狀態保持不變。

## 管理員功能

管理員額外可見：導出 Excel、新增/編輯/刪除數據、批量替換等功能。

## 提示

- 搜索為後端查詢，結果不立即變化是因為防抖延遲
- 篩選器選項受當前搜索條件影響，不一定是全表完整值
