# 方言地圖

檢視方言資料的空間分佈，是查詢和比較結果的地圖展示頁面。

![方言地圖概覽](/tutorial/menu-map-view/01-overview.webp)

## 頁面來源

本頁通常作為其他功能的結果展示目的地：

- 查字、查中古、查音位、查調等操作後切換到地圖標籤頁檢視
- 比較功能的結果直接在地圖頁展示
- 分割槽繪圖的結果也在此展示

## 顯示規則

地圖繪圖預設使用佔比最高的音值；如果有多個音值佔比差不多，會一起顯示：

- 大於 50%：不帶括號
- 35%~50%：帶括號，但不帶 `*`
- 20%~35%：帶括號和星號（`*`）
- 小於 20%：不顯示在地圖上

![佔比顯示規則](/tutorial/menu-map-view/03-ratio-rules.webp)

## 互動功能

點選地圖上的方言點，彈窗查詢詳情：

![點選地圖上的點彈窗檢視詳情](/tutorial/menu-map-view/04-click-detail.webp)

彈窗內可繼續細分查詢，和結果頁面一致：

![彈窗內細分查詢](/tutorial/menu-map-view/05-popup-query.webp)

開啟右上角「檢視地名」開關，地圖上直接顯示各點名稱：

![檢視地名開關](/tutorial/menu-map-view/06-show-names.webp)

點選地名標籤也會彈出地點詳情：

![點選地點名稱彈窗](/tutorial/menu-map-view/07-name-popup.webp)

支援全屏展示，方便截圖：

![全屏展示](/tutorial/menu-map-view/08-fullscreen.webp)

![展示頁面效果](/tutorial/menu-map-view/09-page-display.webp)

可切換不同底圖（街道圖、地形圖等）：

![切換底圖](/tutorial/menu-map-view/10-switch-basemap.webp)

## 模式切換

- **特徵模式**：顯示自定義特徵資料，上方有特徵下拉選單
- **比較模式**：顯示比較結果，顏色標註相同/部分相同/不同
- **普通模式**：顯示標準查詢或分割槽繪圖的點資料

## 自定義資料

登入後可開啟「自定義資料」開關，在地圖上同時顯示公開資料和自己的資料。

## 提示

- 點選地圖會把經緯度傳給自定義資料面板，方便新增新資料
- 未登入時不能開啟「自定義資料」開關
- 預設使用點聚合顯示，放大後顯示詳細內容
