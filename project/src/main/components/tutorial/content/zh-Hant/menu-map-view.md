# 方言地圖

檢視方言資料的空間分佈，是查詢和比較結果的地圖展示頁面。

## 如何使用

本頁通常作為其他功能的結果展示目的地：
- 查字、查中古、查音位、查調等操作後切換到地圖標籤頁檢視
- 比較功能的結果直接在地圖頁展示
- 自定義特徵查詢後自動跳轉到此頁

## 功能

- 在地圖上顯示方言點的讀音或特徵資料
- 支援點聚合顯示，放大後顯示詳細內容
- 右上角開關切換顯示地名標籤
- 點選地圖上的點彈窗檢視詳情
- 支援全屏展示，方便截圖
- 可切換不同底圖（街道圖、地形圖等）

## 模式切換

- **特徵模式**：顯示自定義特徵資料，上方有特徵下拉選單
- **比較模式**：顯示比較結果，顏色標註相同/部分相同/不同
- **普通模式**：顯示標準查詢或分割槽繪圖的點資料

## 自定義資料

登入後可開啟「自定義資料」開關，在地圖上同時顯示公開資料和自己的資料。

## 提示

- 點選地圖會把經緯度傳給自定義資料面板，方便新增新資料
- 未登入時不能開啟「自定義資料」開關
