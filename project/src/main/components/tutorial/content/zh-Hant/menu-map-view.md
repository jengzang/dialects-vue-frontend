# 方言地圖

查看方言數據的空間分布，是查詢和比較結果的地圖展示頁面。

## 如何使用

本頁通常作為其他功能的結果展示目的地：
- 查字、查中古、查音位、查調等操作後切換到地圖標籤頁查看
- 比較功能的結果直接在地圖頁展示
- 自定義特徵查詢後自動跳轉到此頁

## 功能

- 在地圖上顯示方言點的讀音或特徵數據
- 支持點聚合顯示，放大後顯示詳細內容
- 右上角開關切換顯示地名標籤
- 點擊地圖上的點彈窗查看詳情
- 支持全屏展示，方便截圖
- 可切換不同底圖（街道圖、地形圖等）

## 模式切換

- **特徵模式**：顯示自定義特徵數據，上方有特徵下拉選單
- **比較模式**：顯示比較結果，顏色標注相同/部分相同/不同
- **普通模式**：顯示標準查詢或分區繪圖的點數據

## 自定義數據

登入後可開啓「自定義數據」開關，在地圖上同時顯示公開數據和自己的數據。

## 提示

- 點擊地圖會把經緯度傳給自定義數據面板，方便添加新數據
- 未登入時不能開啓「自定義數據」開關
