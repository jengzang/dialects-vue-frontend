# 字表合併

按參考表的漢字順序，批量合併多個字表檔案。

## 三步流程

### 步驟 1：準備參考表

- 上傳或使用預設參考表
- 參考表必須有「單字」列，其順序即為最終合併順序
- 支持上傳自定義參考表（.xlsx、.xls，上限 3 MB）
- 可預覽預設參考表後一鍵套用

### 步驟 2：上傳待合併檔案

- 一次可選多個檔案（最多 20 個）
- 上傳的字表需滿足列名要求：
  - 漢字列：「單字」、「phrase」、「單字」、「漢字」、「漢字」
  - 音標列：「IPA」、「ipa」、「音標」、「音標」、「syllable」
  - 注釋列：「注釋」、「注釋」、「解釋」、「notes」
- 每個檔案可單獨移除

### 步驟 3：合併與下載

- 點擊「開始合併」，顯示進度
- 參考表之外的字會在末尾補充
- 一字多音以「;」分隔
- 注釋存為 Excel 批注
- 完成後下載合併結果

## 提示

- 需登入才能使用
- 原始數據質量不佳時建議先去「字表檢查」整理
- 可點擊「重設」清除所有步驟重新開始
