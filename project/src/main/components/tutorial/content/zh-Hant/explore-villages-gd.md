# 廣東自然村樹狀圖

按行政層級瀏覽廣東自然村數據，支持樹狀展開和方言地圖可視化。

數據來源：《全粵村情》方言數據（均為站長錄入），注意存在行政區劃對應、調查精確度、人工錄入等誤差來源。

## 基本操作

![廣東自然村樹狀圖——按行政層級展開](/tutorial/explore-villages-gd/01-tree.jpg)

![地圖彈窗——點擊 🌍 查看](/tutorial/explore-villages-gd/02-map.jpg)


1. 頁面載入市級清單
2. 點擊目標市卡片上的「載入」
3. 逐級展開樹狀結構：市 → 區縣 → 鄉鎮 → 行政村 → 自然村
4. 點擊節點右側的 🌍 打開地圖彈窗

## 節點資訊

最底層自然村節點顯示：
- 村名
- 方言分布
- 經緯度（如有）

## 搜索

- 搜索框只比對已載入的節點
- 命中節點的高層路徑自動展開
- 命中文本高亮顯示

## 地圖功能

- 點擊分支節點的 🌍：遞歸收集所有下屬自然村並繪制
- 點擊底層節點的 🌍：僅顯示該村
- 地圖彈窗支持切換底圖、重設視角、全屏
- **方言模式**：以不同顏色標示不同方言，不聚合
- **村名模式**：點聚合顯示

## 提示

- 看不到村落通常是因為該市還沒按「載入」
- 地圖上點數少於樹節點數是因為部分村落沒有經緯度
- 目前只有廣東省數據
- 瓦片地圖源在國外，可能需要科學上網
