# 管理詞表

對自己的詞表進行線上編輯、批次替換、增刪詞條等操作。編輯權限的使用者只能更改自己提交的詞條。

![編輯功能概覽](/tutorial/menu-vocabulary/18-编辑功能概览.webp)

## 建立詞條

點選新增按鈕後，彈窗填入資料。標準詞必填，方言詞和音標二者填入其一即可。

![建立詞條彈窗](/tutorial/menu-vocabulary/19-创建词条弹窗.webp)

## 刪除詞條

點選最右側的紅色 × 按鈕，確認彈窗後即可刪除。

![刪除詞條確認](/tutorial/menu-vocabulary/20-删除词条确认.webp)

## 批次編輯單元格

進入編輯模式後，可以像 Excel 一樣自由更改單元格。最後點選右上角的「提交」即可儲存。

![批次編輯單元格](/tutorial/menu-vocabulary/21-批量编辑单元格.webp)

## 批次替換

進入編輯模式後，點選右上角「批次替換」按鈕。

![批次替換按鈕](/tutorial/menu-vocabulary/22-批量替换按钮.webp)

先選擇要批次替換的列：

![批次替換選擇列](/tutorial/menu-vocabulary/23-批量替换选择列.webp)

然後輸入待替換的內容和替換後的內容。有兩種匹配模式：

- **完全匹配**：只有當整個單元格與查詢內容完全一致時才替換。例如查詢「廣州」，只有「廣州」會被替換，「廣州市」不會
- **包含匹配**：只要單元格內任意位置包含查詢內容即替換。例如查詢「廣州」，則「廣州」、「廣州市」、「廣州話」都會被替換

輸入完成後先點選「預覽」：

![批次替換預覽](/tutorial/menu-vocabulary/24-批量替换预览.webp)

可以選擇「僅替換當前分頁」或「全表替換」。建議使用僅當前頁替換，可以預覽到具體替換內容：

![替換當前分頁預覽](/tutorial/menu-vocabulary/25-替换当前分页预览.webp)

全表替換無法預覽，不太建議使用：

![全表替換提示](/tutorial/menu-vocabulary/26-全表替换提示.webp)

確認後點擊「替換」按鈕：

![確認替換](/tutorial/menu-vocabulary/27-确认替换.webp)

替換完成：

![替換結果](/tutorial/menu-vocabulary/28-替换结果.webp)

![替換完成](/tutorial/menu-vocabulary/29-替换完成.webp)

## 篩選與排序

**按列篩選**：點選列名即出現篩選彈窗，勾選要篩選的值即可過濾資料。

![按列篩選](/tutorial/menu-vocabulary/30-按列筛选.webp)

**排序**：點選列名旁的箭頭可進行升序或降序排序。

![排序功能](/tutorial/menu-vocabulary/31-排序功能.webp)

## 更新地點資訊

如果地點資訊需要更新，可以在地點資訊頁面進行更改。

![更新地點資訊頁面](/tutorial/menu-vocabulary/32-更新地点信息页面.webp)

點選編輯會彈出編輯視窗：

![編輯地點彈窗](/tutorial/menu-vocabulary/33-编辑地点弹窗.webp)

## 管理權限

擁有管理權限的使用者可以檢視詳細的編輯日誌：

![編輯日誌](/tutorial/menu-vocabulary/34-编辑日志.webp)

必要時可以進行回滾操作：

![管理回滾](/tutorial/menu-vocabulary/35-管理回滚.webp)

同時，資料庫每小時自動備份一次，即使改壞了也能及時恢復。

## 提示

- 編輯模式下修改後別忘了點選「提交」儲存
- 批次替換建議使用「僅替換當前分頁」模式，可以預覽確認替換內容
- 管理權限使用者可以檢視編輯日誌並進行回滾
