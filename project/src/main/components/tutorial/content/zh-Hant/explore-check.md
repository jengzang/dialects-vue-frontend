# 字表檢查

上傳方言字表檔案，自動檢查「非單字」「異常音標」「缺聲調」等常見問題，並提供在線編輯修正功能。

## 基本操作

1. 登入帳號
2. 選擇數據格式（音典、跳跳老鼠、縣誌）
3. 上傳檔案（支持 .xlsx、.xls、.doc、.docx、.tsv，單檔案上限 3 MB）
4. 系統自動分析並展示錯誤統計

## 檢查功能

- **非單字檢查**：檢測是否包含非單字內容
- **異常音標檢查**：檢測 IPA 音標格式異常
- **缺聲調檢查**：檢測缺少聲調的音節

## 統計與篩選

- 左側整理錯誤類型、調值統計、聲母與韻母統計
- 點擊錯誤列自動跳轉到對應數據行
- 點擊聲母或韻母統計可直接篩選
- 搜索框支持快速定位

## 編輯模式

切換到編輯模式後：
- 可直接修改單元格值
- 可標記整列刪除
- 支持 IPA 批量替換
- 支持入聲調/舒聲調批量替換
- 批量儲存後系統重新分析最新內容
- 完成後下載更改後的檔案

## 提示

- 格式選錯會整份資料錯誤拆欄，上傳前務必確認
- 退出編輯模式時未儲存的修改會被清空
- 伺服器做了限流，上傳載入較慢請耐心等待
