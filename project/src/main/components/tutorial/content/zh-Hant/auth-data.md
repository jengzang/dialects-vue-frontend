# 我的資料

管理自己上傳的自定義方言資料。支援批次新增、編輯、刪除。

## 基本操作

1. 需登入才能訪問
2. 頁面顯示所有已上傳的自定義資料
3. 右上角顯示總筆數和已選筆數

## 單行編輯

點選每行右側的「編輯」按鈕，開啟編輯彈窗，修改後儲存。

## 批次新增

- 點選「批次新增」開啟彈窗
- 可逐行新增，或直接貼上 Tab 分隔、換行分筆的資料
- 每筆資料包含：簡稱、音典分割槽、經緯度、聲韻調、特徵、值、說明
- 必填各列完整才能提交
- 一次最多提交 50 行

## 批次編輯

1. 勾選要修改的資料
2. 點選「批次編輯」
3. 在彈窗中修改後提交

## 批次刪除

1. 勾選要刪除的資料
2. 點選「批次刪除」
3. 確認後執行

## 搜尋與分頁

- 搜尋框即時篩選表格資料
- 分頁大小可切換 10/20/50/100
- 表頭全選只選當前頁的資料

## 提示

- 批次編輯實際是先刪後建，提交前請確認資料完整
- 返回按鈕跳轉到 `/auth`，不是瀏覽器後退
