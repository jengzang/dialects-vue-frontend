# 我的數據

管理自己上傳的自定義方言數據。支持批量新增、編輯、刪除。

## 基本操作

1. 需登入才能訪問
2. 頁面顯示所有已上傳的自定義數據
3. 右上角顯示總筆數和已選筆數

## 單筆編輯

點擊每行右側的「編輯」按鈕，打開編輯彈窗，修改後儲存。

## 批量新增

- 點擊「批量新增」打開彈窗
- 可逐行添加，或直接粘貼 Tab 分隔、換行分筆的數據
- 每筆數據包含：簡稱、音典分區、經緯度、聲韻調、特徵、值、說明
- 必填欄位完整才能提交
- 一次最多提交 50 筆

## 批量編輯

1. 勾選要修改的數據
2. 點擊「批量編輯」
3. 在彈窗中修改後提交

## 批量刪除

1. 勾選要刪除的數據
2. 點擊「批量刪除」
3. 確認後執行

## 搜索與分頁

- 搜索框即時篩選表格數據
- 分頁大小可切換 10/20/50/100
- 表頭全選只選當前頁的數據

## 提示

- 批量編輯實際是先刪後建，提交前請確認數據完整
- 返回按鈕跳轉到 `/auth`，不是瀏覽器後退
