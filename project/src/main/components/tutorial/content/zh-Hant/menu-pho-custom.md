# 音素查詢

按自選分類維度重新整理音系數據，支持三維交叉分類。

## 基本操作

1. 選擇分析類別：聲母、韻母或聲調
2. 輸入地點（最多 10 個）
3. 選擇三個分類維度：
   - **橫向**：第一層分類（如清濁、開合口）
   - **縱向**：第二層分類（如發聲部位、韻攝）
   - **格內**：單元格內的細分（如聲母、等）
4. 點擊「查詢」

## 典型用例

- 橫向按清濁、縱向按發聲部位、格內按聲母 → 整理出每個聲母音值的數量分布
- 橫向按開合口、縱向按韻攝、格內按等 → 整理出各韻母音值的數目
- 橫向按清濁、縱向按調類、格內按聲母 → 整理出各分類中調類的數目

## 交互

- 點擊單元格可彈窗查看詳情
- 可自由組合三維分類，靈活探索音系數據
- 查詢成功後網址自動同步，方便分享

## 提示

- 切換字表後可選分類欄位會跟著變化
- 此功能適合做探索性分析，從不同角度觀察音系結構
