# 陽春口語

展示陽春地區的口語語料資料，以表格形式呈現本字考、IPA 讀音、粵拼、詞性、釋義及例詞例句。

## 資料特點

相比全粵村情資料，陽春資料所用更多為本字（而非同音字），資料經過站長核對，更為準確。

## 主要欄位

- 本字考
- IPA
- 粵拼
- 來源
- 聲母、韻母、音調
- 詞性
- 釋義
- 例詞例句
- 待校及說明

## 使用方式

- 用表格篩選器按欄位過濾資料
- 可點選標題旁的村落按鈕跳轉到陽春自然村頁面
![陽春口語.webp](/tutorial/explore-yc-spoken/陽春口語.webp)

## 提示

- 不是所有欄位都支援篩選（IPA、粵拼、釋義、例句等不可篩選）
- 適合陽春方言研究者深入查閱
