# 陽春口語

展示陽春地區的口語語料數據，以表格形式呈現本字考、IPA 讀音、粵拼、詞性、釋義及例詞例句。

## 數據特點

相比全粵村情數據，陽春數據所用更多為本字（而非同音字），數據經過站長核對，更為準確。

## 主要欄位

- 本字考
- IPA
- 粵拼
- 來源
- 聲母、韻母、音調
- 詞性
- 釋義
- 例詞例句
- 待校及說明

## 使用方式

- 用表格篩選器按欄位過濾數據
- 可點擊標題旁的村落按鈕跳轉到陽春自然村頁面

## 提示

- 不是所有欄位都支持篩選（IPA、粵拼、釋義、例句等不可篩選）
- 加載速度較快（數據經過優化）
- 適合陽春方言研究者深入查閱
