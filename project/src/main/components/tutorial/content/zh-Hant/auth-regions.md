# 自定義分區

創建和管理自己的方言分區方案，用於地點搜索和地圖繪制時的區域篩選。

## 基本操作

1. 登入後訪問此頁
2. 查看已有分區列表（每張卡片顯示分區名稱、地點數、創建日期、描述）
3. 點擊「新增」創建分區

## 創建分區

1. 填寫分區名稱
2. 透過「選擇地點」按鈕或手動輸入添加地點
3. 手動輸入時用空格或換行分隔地點，系統自動去重
4. 每個分區最多 1000 個地點
5. 地點數 ≥ 1 且名稱非空時才能儲存

## 編輯與刪除

- 點擊卡片上的鉛筆按鈕進入編輯（分區名稱不可修改）
- 刪除分區前會彈出確認框

## 應用場景

- 自定義分區可在查詢、比較等功能中作為地點篩選條件
- 與帳號綁定，不同設備登入均可使用
- 配合自定義數據使用效果更佳

## 提示

- 下方會顯示 M（手動輸入但不在分區樹中的地點數）和 T（可在分區樹中識別的地點數）
- 新增分區時如果名稱與已有分區重復，系統會提示確認
