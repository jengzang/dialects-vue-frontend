# 比較調類

比較兩個調類在各方言點是否合流。適合用來分析特定區域內的調類歸併現象。

## 基本操作

1. 在調類勾選區勾選第一個調類（如陰上）
2. 再勾選第二個調類（如陽上）
3. 輸入地點或分割槽
4. 點選「比較」，直接跳轉到地圖頁面
![比較調類1.webp](/tutorial/menu-compare-tone/比较调类1.webp)

## 結果解讀

地圖上以顏色標註兩個調類的關係：

- **完全合併**：兩個調類調值完全相同
- **可能合併**：調值接近，有合併傾向
- **不合並**：調值明顯不同
- 灰色：無資料

## 典型用例

- 珠三角一帶的陽上、陰去合併情況
![比較調類2.webp](/tutorial/menu-compare-tone/比较调类2.webp)
- 客家話陰平、陰去合併情況
![比較調類3.webp](/tutorial/menu-compare-tone/比较调类3.webp)
- 南方方言的陰入、陽入合併情況
![比較調類4.webp](/tutorial/menu-compare-tone/比较调类4.webp)
- 四邑、莞寶的陰平、陰去、陽上調類格局

## 限制

- 一次只能比較 2 個調類，選滿後其他調類自動停用
- 需取消已選中的某個調類才能更換組合

## 提示

- 有些方言點資料中沒有註明某些調類（如陽上），會顯示無資料
- 如需檢視完整調類系統，先用「查調」
- 可一次性分析多個地點，觀察區域性的調類歸併趨勢
