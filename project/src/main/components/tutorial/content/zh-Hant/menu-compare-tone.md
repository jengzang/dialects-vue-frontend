# 比較調類

比較兩個調類在各方言點是否合流。適合用來分析特定區域內的調類歸並現象。

## 基本操作

![比較調類界面](/tutorial/menu-compare-tone/overview.jpg)

*比較調類——地圖顏色標注合流情況*

1. 在調類勾選區勾選第一個調類（如陰上）
2. 再勾選第二個調類（如陽上）
3. 輸入地點或分區
4. 點擊「比較」，直接跳轉到地圖頁面

## 結果解讀

地圖上以顏色標注兩個調類的關係：

- **已合流**：兩個調類調值完全相同
- **可能合流**：調值接近，有合併傾向
- **未合流**：調值明顯不同
- 灰色：無數據

## 典型用例

- 珠三角一帶的陽上、陰去合併情況
- 客家話陰平、陰去合併情況
- 南方方言的陰入、陽入合併情況
- 四邑、莞寶的陰平、陰去、陽上調類格局

## 限制

- 一次只能比較 2 個調類，選滿後其他調類自動禁用
- 需取消已選中的某個調類才能更換組合

## 提示

- 有些方言點資料中沒有注明某些調類（如陽上），會顯示無數據
- 如需查看完整調類系統，先用「查調」
- 可一次性分析多個地點，觀察區域性的調類歸並趨勢
