# 音值比較

比較所選各點的音值對應關係。

## 基本操作

1. 輸入地點2~5個
2. 滑動選擇連線最少字數和節點最少字數
3. 選擇是否最佳化連線、是否忽略多音字
4. 點選「開始比較」
![音值比較1.webp](/tutorial/menu-compare-phonetic/音值比较1.webp)

## 結果解讀

1. 更直觀地比較所選各點的音值對應關係
2. 可切換聲母、韻母或聲調進行比較
![音值比較2.webp](/tutorial/menu-compare-phonetic/音值比较2.webp)
3. 點選音值會彈窗顯示對應音值所有的漢字
![音值比較3.webp](/tutorial/menu-compare-phonetic/音值比较3.webp)
![音值比較4.webp](/tutorial/menu-compare-phonetic/音值比较4.webp)
4. 點選連線會彈窗顯示兩地音值對應的漢字
![音值比較5.webp](/tutorial/menu-compare-phonetic/音值比较5.webp)

## 適用場景

- 比較兩個音值在不同區域的分佈差異
- 配合查音位進行音類分合分析

## 提示

- 此功能側重音值的對應關係
- 如需瞭解音值的中古來源，先用「查音位」
- 如需比較漢字讀音，用「比較漢字」
