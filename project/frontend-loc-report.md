## 参数说明

| 参数 | 含义 | 示例 |
|---|---|---|
| 第 1 个数字 | min，最小总行数 | `npm run num -- 200` |
| 第 2 个数字 | top，只展示前 N 个 | `npm run num -- 100 50` |
| `--root` | 扫描目录 | `--root src/main` |
| `--min` | 最小总行数 | `--min 100` |
| `--top` | 只展示前 N 个 | `--top 50` |
| `--ext` | 扫描扩展名 | `--ext vue,js,ts,scss` |
| `--kind` | 文件种类筛选：all/vue/script/style/template/other | `--kind script` |
| `--out` | 输出文件 | `--out frontend-loc-report.md` |
| `--format` | `markdown` / `json` / `csv` | `--format json` |
| `--sort` | 排序字段 | `--sort style` |
| `--order` | `desc` / `asc` | `--order asc` |
| `--type` | 类型筛选 | `--type style-heavy` |
| `--style` | 样式筛选 | `--style css` |
| `--summary-only` | 只输出汇总 | `--summary-only` |

## 类型说明

- `script-heavy`：script 占比 >= 50%，通常说明 JS/TS 逻辑偏重。
- `style-heavy`：style 占比 >= 40%，通常说明 CSS/SCSS 样式偏重。
- `template-heavy`：template 占比 >= 50%，通常说明模板结构偏重。
- `mixed`：template / script / style 都比较多，适合进一步拆组件或抽 composable。

## 注意

- `.vue` 会拆分 `template / script / style`。
- 独立 `.js/.ts/.jsx/.tsx` 会整体计入 `script`。
- 独立 `.css` 会整体计入 `style + css`。
- 独立 `.scss/.sass` 会整体计入 `style + scss`。
- 独立 `.less/.styl/.stylus` 会整体计入 `styleOther`。
- 独立 `.html/.htm` 会整体计入 `template`。
- `other` 在 `.vue` 中主要包含 SFC 标签行、块间空行、顶层注释等。
