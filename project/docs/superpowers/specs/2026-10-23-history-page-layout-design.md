# History 页面阅读布局

## 目标

让开发历程和开发感悟成为两个清楚分开的阅读部分，避免整页长内容被包进一张高大的玻璃面板。

## 设计决定

- 移除 `AboutHistory.vue` 根容器上的 `glass-panel`，保留页面宽度、标题、内边距和现有竖屏字号。
- 保留标题、历史筛选、更新数量和 V1–V5 时间线的现有顺序与行为。版本阶段继续使用标题、间距和分隔线区分，不逐阶段增加卡片。
- 将开发感悟保留在本页末尾，作为独立的语义章节，用章节标题、上方间距和分隔线与时间线分开。
- 开发感悟不增加独立玻璃面板；移除各段透明背景上的单段阴影，让段落作为一个连续文本区阅读。
- 保持更新内容、链接、重要更新筛选逻辑、路径和中英文案不变。

## 方案取舍

保留一张包住整页的面板改动最少，但会让时间线和感悟看起来属于同一块长内容，且全局悬停阴影作用于整张大卡片。将时间线与感悟各做成一张大面板能明确分组，但仍给两段长内容都增加厚重的表面层。采用普通页面流并单独划分感悟章节，更符合阅读页的用途，也与 About 其他页面的自然内容布局一致。

## 验证

实施后运行历史页现有 Vitest 测试、目标 Vue 文件 ESLint 与 `git diff --check`。检查桌面和竖屏下标题、筛选器、版本分隔、感悟分隔与文字缩放；确认没有修改历史文案或链接。

## 范围边界

只调整 `AboutHistory.vue` 的容器层级与本地样式，以及必要的历史页测试。不修改共享面板样式、历史数据、路由、其他 About 页面或 `glass-panel` 的全站行为。
