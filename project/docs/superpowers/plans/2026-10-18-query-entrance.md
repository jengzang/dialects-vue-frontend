# 词表与语保查询入口改造

**目标：** 两页采用用户选定的居中查询大框，点击查询后平滑滚动到原有顶部查询区；向上滚动自然返回大框。顶部输入框不悬浮，保留原样式和即时查询。模式切换移至条件栏，横屏显示图标与文字，竖屏仅图标。

**实施方式：** 在当前 dev 分支依次完成两个独立步骤，每步验证、CR、定向提交。保留当前未提交的路由、API、sitemap 和已有计划文件，不安装依赖。

## 步骤一：共用模式切换器

- [ ] 为共享切换器添加实际挂载交互测试，验证选择事件、选中状态和无障碍名称。
- [ ] 新增 `src/components/common/ResultViewSwitcher.vue`，组合共享分段样式与 Phosphor 图标。
- [ ] 词表从 `VocabularyPage.vue` 移除模式选择器，在 `VocabularyTopControls.vue` 的条件栏接入共享切换器，保留字音注释特殊模式及既有路由同步。
- [ ] 语保移除旧模式按钮，在独立条件栏使用同一组件，保留现有数据加载逻辑。
- [ ] 执行相关 Vitest、定向 ESLint 和 diff CR，提交本步骤。

## 步骤二：居中查询入口

- [ ] 添加挂载测试，验证大框输入、候选选择均不提交，只有查询按钮提交并进入紧凑查询区；支持减少动画偏好和逆向滚动。

- [ ] 执行回归测试、定向 ESLint、Vite 构建和浏览器横竖屏验证，检查输入、模式切换、候选与回滚动，CR 后提交。
