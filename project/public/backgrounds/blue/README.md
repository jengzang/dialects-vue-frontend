# 山河有音背景（方案 A，共用蓝色素材）

用于 MenuLayout、ExploreLayout 的四种配色，首页则从核心功能区块开始显示，进入该区域后才加载，首屏地球不使用。所有主题共用本目录的图片，不生成或下载四套素材；蓝色保留原始底图，浅色、绿色、深色保留原主题底色，并在 Canvas 重绘时一次性调色。切换主题复用已加载资源，不持续逐帧执行滤镜。

古籍、题字、山水与地图分层，避免拉伸或整幅裁切主要元素。古籍贴左下角，地图保留统一投影。屏幕宽高比不大于 1 时采用竖屏构图。背景固定于视口，不拦截鼠标操作，也不随页面内容高度拉长。

国界、34 个省级区域、三级河流预先合成为透明 `map.webp`，背景运行时不再读取 GeoJSON；点位仍读取 `/data/dots.json`，不烘焙到图片中。地图与点位共用 Albers 等积投影，投影边界记录在 `src/utils/ui/blueBackgroundMapProjection.json`。资源在布局间复用；山水避让古籍、题字和地图北纬 17° 以北的区域。

compact 模式不加载此背景。任意背景图片加载失败，背景和页脚均使用原来的默认样式。

更新国界、省界或河流后，在 `project` 目录运行 `python3 scripts/generate-blue-background-map.py`，同时更新 WebP 与投影参数。此离线脚本使用 Python/Pillow，不引入前端依赖。

当前采用低体积素材：《方言》缩至 720 像素宽、WebP 质量 35；山水尺寸为初版的 60%、质量 30；小篆保留原尺寸并压缩调色板，绘制不透明度为 84%；地图主体宽 1000 像素，四周留 4 像素透明边缘，32 色调色板。压缩只改变素材精度，页面显示尺寸与地理投影保持一致。

## 素材来源

- `fangyan.webp`：用户提供的透明《方言》图片，裁掉顶部 210 像素空白纸边，转为冷白纸张、蓝灰字迹，增加明显的右上圆弧与边缘羽化。素材不透明度约 57%，绘制时再乘 25%。
- `mountains-upper.webp`、`mountains-lower.webp`：用户提供的视觉参考截图中不含 UI 的山景局部，保留原始水墨纹理，进行蓝灰调色、透明化和边缘羽化。
- `quote-landscape.webp`、`quote-portrait.webp`：繁体小篆题字「蓋時有古今，地有南北，字有更革，音有轉移，亦勢所必至」，不显示正文标点。左侧署名「——陳第《毛詩古音考》」。汉字由真实字体排版，字体缺少的破折号与书名号单独绘制为竖排标点。
- `base.webp`：浅蓝白底色纹理。
- `map.webp`：由项目 `public/data/gis` 的国界、省界及三级河流生成，不含调查点；保留完整地理范围并在四边增加透明像素，避免描边被切断。

小篆使用王心怡、季旭昇製作，中研院小學堂釋出的「崇羲篆體」。字体文件未修改，站点仅使用排版后的图片。
