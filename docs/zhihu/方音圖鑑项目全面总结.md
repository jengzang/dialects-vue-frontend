# 方音圖鑑 — 项目全面总结

> 本文档根据「方音圖鑑」网站的实际功能及知乎专栏 7 篇介绍文章整理而成，供其他 AI 快速理解项目全貌。

---

## 一、项目概况

**项目名称**：方音圖鑑（Dialects Atlas）

**网站地址**：https://dialects.yzup.top/

**作者**：不羁（jengzang）

**定位**：专注于中古音韵地位分析、方言比较、地理语言学的在线工具平台，同时集成字表处理、语保数据展示、自然村方言可视化、Praat 声学分析等多种功能，是一个持续成长中的方言研究综合平台。

**开源仓库**：
- 前端：https://github.com/jengzang/dialects-vue-frontend（Vue 框架 + 原生 js）
- 后端：https://github.com/jengzang/dialects-backend（Python FastAPI）
- 字表预处理：https://github.com/jengzang/dialects-build

**当前规模**（2026年7月）：
- 日均访问约 300 人次
- API 调用约 5000 次/天
- 由一名本科生独立开发运营（从字表处理、后端 API 到前端界面皆一人完成）

## 三、功能模块详解

### 模块 A：核心音韵查询（4 个子功能）

文章：《「方音图鑑」核心查询功能》

**A1. 查中古 — 按中古地位整理读音**

- 输入维度：支持 12 种类型：摄、韵、等、呼、清浊、系、组、母、舒入、调、发音部位、发声方式
- 支持多种组合（笛卡尔积），自动过滤无效组合
- 可选分析对象：声母 / 韵母 / 声调
- 可切换韵书：《广韵》《方言调查字表》《集韵》、上古音、《洪武正韵》等（部分仍在测试）
- 地点输入：模糊匹配（简繁均可、行政区划亦可匹配），也可通过「地图集分区」或「音典分区」批量选取
- **结果页面**：
  - 表格展示，多音字展示多个读音
  - 点击统计按钮 → 细分查询（如查韵母时点击统计可看声母、声调分布）
  - 点击音值 → 反查音节来源
  - 点击地位 → 按该维度再次组合查询
  - 点击地名 → 弹窗展示方言点详细信息
  - 支持多窗口并行对比
  - 筛选功能（按音值筛选）
  - 两种显示模式：全显模式（带方框）、主体模式（精简，自动过滤低频地位）
- **地图模式**：
  - 按占比分层显示（>50% 无括号，35–50% 带括号，20–35% 带括号和星号，<20% 不显示）
  - 点击地图上的点 → 弹窗细分查询
  - 可查看地名标签
  - 支持全屏、切换底图
- **2026.7 更新 — 文白读**：
  - 查中古结果中：红色=文读，蓝色=白读，紫色=文白同形，绿色=普通多音字
  - 查字结果中：蓝色=白读，红色=文读，黑色=普通汉字
  - 查音位结果同样支持文白读着色
  - 当前仅部分字表支持

**A2. 查音位 — 分析音位的中古来源**

- 输入方式与查中古类似（选择维度 → 输入音节 → 选择地点/分区）
- 计算复杂度高，耗时较长，建议减少地点数量
- 结果同样支持弹窗细分查询、地图展示

**A3. 查字 — 查询字音、地位**

- 输入汉字 + 地点/分区
- 结果：各地读音、注释、中古地位
- 地图展示读音的地理分布

**A4. 查调 — 查询调值、调类**

- 仅需输入地点或分区，接口轻量
- 登录用户可不受限制地同时查询多个地点
- 结果以表格呈现，不同调类标不同颜色
- 地图可切换不同调类绘制

### 模块 B：方言比较

文章：《「方音圖鑑」方言比较功能》

链接：https://dialects.yzup.top/menu/compare/

**B1. 比较汉字**

- 选择汉字 + 选择方言分区/地点
- 以颜色直观展示差异：
  - 绿色 = 完全相同
  - 黄色 = 部分相同
  - 红色 = 完全不同
- 支持全屏放大查看
- 点击后弹窗显示具体字音细节
- 可用于分析特定音韵现象的地域分布（如边擦音分布、颚化、阴入等）

**B2. 比较中古**

- 两组中古筛选条件分别设置（组1 vs 组2）
- 支持复杂的音韵地位组合（如宕江分合分析）
- 后端处理多条件时较慢
- 采用**相似度算法**：
  - 总重叠度 = Σ min(组1读音占比, 组2读音占比)
  - 高重叠度 → 绿色；中等 → 黄色；低 → 红色
  - 该算法简单但依赖音值，适用于同一地点内部比较

**B3. 比较调类**

- 分析不同地点间调类合并情况
- 示例：珠三角阳上-阴去合并、四邑莞宝的阴平-阴去-阳上合并关系
- 支持一次性分析多地点的入声合并情况

文章：《方言分析工具「深入分析单个方言点」》

- 自定义输入模式：单次最多分析 100 个地点

### 模块 E：方言字表处理工具

文章：《方言字表处理工具》

链接：https://dialects.yzup.top/explore/tools/check

**E1. 字表检查**

- 自动检查：非单字、异常音标、缺声调
- 自动拆分声韵调，提供声韵统计、调类调值统计
- 支持在线编辑：修改单元格、批量编辑声韵、批量替换调值、删行

- 链接：https://dialects.yzup.top/explore/tools/derive

### 模块 H：声学分析工具（Praat 网页版）

文章：《声学分析工具(praat网页版)》

链接：https://dialects.yzup.top/explore?page=praat

基于 `praat-parselmouth` Python 包将 Praat 核心算法集成到网站后端，提供现代 Web 界面。所有代码开源。

**需要登录**才能使用（Praat 算法吃 CPU，服务器配置有限）。

**H1. 语音上传与截取**

- 支持拖拽上传，格式：WAV、MP3、M4A、WebM、OGG、FLAC、AAC 等
- 支持直接在网站上录音
- 录音后可拖动截取分段，无需额外剪辑
- 移动端适配（推荐手机录音，音质优于电脑麦克风）

**H2. 分析模式**

- **单音节模式**：精确截取单个音节，适用于元音空间分析
- **连续语流模式**：后端自行分段，有误差，元音空间不太适用，适合基频定调（可一次上传多个调类完成石峰 T 值法 5 度图绘制）

**H3. 分析模块（共 7 个）**

- 基本信息：音频时长、采样率
- 基频分析：调值特征、五度标调计算、基频曲线 → 基频定调依赖此模块
- 强度分析：平均强度、强度范围、强度轨迹图
- 共振峰分析：共振峰轨迹 → 元音空间依赖此模块
- 音质分析：谐噪比、基频微扰、振幅微扰
- 音段分析：单音节→韵核(rime_core)+音节段(syllable_like)；连续语流→voiced/speech/silence
- 频谱图分析：频率-时间能量分布（仅限 3 秒内音频，加载较慢）

**H4. 分辨率设置**

- 快速、标准、高精度三种模式

**H5. 结果展示**

- **分析结果卡片**：五度标调数值、基频轨迹图（黄色标注韵核）、强度轨迹、共振峰轨迹、频谱图
- **元音空间**：展示元音音值及滑动轨迹。推荐单音节模式 + 安静环境 + 精确截取。连续语流模式点会很散。
- **基频定调**：截取各调类的 voiced / rime_core 部分 → 加入列表 → 石峰 T 值法绘制五度图。支持导出到 Excel。移动端可用。

| 数据 | 来源 |
|---|---|
| 核心字表、音韵数据 | 汉字音典（mcpdict）开源数据 |
| 语保词汇/句子 | 中国语言资源保护工程（语保工程）官方公开平台 |
| 全粤村情方言 | 《全粤村情》丛书，作者手动录入 |
| 阳春自然村 | 《阳春县志》，作者校对 |
| 部分资料 | 岭南粤音、泛粤大典、小学堂、粤闽客方言系统 |
| 行政区划 | GIS 空间连接方法对应 |
