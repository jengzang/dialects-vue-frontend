# 主地图点位图层迁移

**目标：** 移除 `MapLibre.vue` 的逐点 DOM Marker，保留六种模式的数据含义、点位交互及已有弹窗业务操作。用户已授权排查边界后执行修复。

**范围：** 只修改主地图及对应测试；保留现有模块组织，不安装依赖。热力图、等值线算法、其他独立地图组件不改造。

**实现：** 圆点使用 MapLibre 图层，文字使用允许重叠的 symbol 图层，保留数据顺序。文字背景使用按颜色共享的可拉伸图片，避免为每个标签生成完整纹理。弹窗仅在命中点位后创建，关闭时卸载 Vue 内容。原始业务对象保留在组件内，GeoJSON 只带渲染属性及索引。迁移可能存在 Canvas/WebGL 与 DOM 字体栅格化的细微差异，须浏览器验证。

## 验收边界

空数据和无效坐标不崩溃；有效点不被聚合或抽样；颜色分配、数据过滤、复位视口含义不变；重合点保持后绘制优先；拖动结束不误开弹窗；地图背景点击继续发出坐标；点位点击保留原有冒泡语义；弹窗关闭卸载且原生返回登记解除；数据更新/样式切换后没有重复监听或过期弹窗。热力图和等值线切换无残留图层。
