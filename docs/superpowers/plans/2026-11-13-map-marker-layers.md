# 主地图点位图层迁移

**目标：** 移除 `MapLibre.vue` 的逐点 DOM Marker，保留六种模式的数据含义、点位交互及已有弹窗业务操作。用户已授权排查边界后执行修复。

**范围：** 只修改主地图及对应测试；保留现有模块组织，不安装依赖。热力图、等值线算法、其他独立地图组件不改造。

**实现：** 圆点使用 MapLibre 图层，文字使用允许重叠的 symbol 图层，保留数据顺序。base 地名的文字和背景合成缓存图片，以恢复整张标签的遮挡顺序；feature 普通文字背景仍按颜色共享可拉伸图片。弹窗仅在命中点位后创建，关闭时卸载 Vue 内容。原始业务对象保留在组件内，GeoJSON 只带渲染属性及索引。迁移可能存在 Canvas/WebGL 与 DOM 字体栅格化的细微差异，须浏览器验证。

## 验收边界

空数据和无效坐标不崩溃；有效点不被聚合或抽样；颜色分配、数据过滤、复位视口含义不变；重合点保持后绘制优先；拖动结束不误开弹窗；地图背景点击继续发出坐标；点位点击保留原有冒泡语义；弹窗关闭卸载且原生返回登记解除；数据更新/样式切换后没有重复监听或过期弹窗。热力图和等值线切换无残留图层。

## 验证记录

代码审查和实际截图对照发现并修正：行政边界覆盖点位、阴影比例、透明颜色回退、比较点悬停层级、文字自动换行、组合附加符号度量错误、固定行高、透明边缘命中、旋转后的响应式字号。普通文字和背景共享；IPA 组合符、emoji 及旗帜按完整字符串绘制并去重。为避免极端文本/不同音标过多时纹理失控，整串文字回退的纹理像素预算约 16M，单图每边不超过 4096 像素；超出预算时降低栅格分辨率，不截断文字或减少点位。3,000 个不同组合音标标签的 WebGL 压测无错误，总纹理像素 16,638,976。

Chrome / Apple M5 Metal GPU，390×844、DPR 3、CPU 降速 4 倍、空底图，同批 3,000 点，单次 1.5 秒平移动画（以下 base 数据记录于整张标签遮挡修复之前）：

| 模式 | 原实现动画帧数 | 新实现动画帧数 | 原实现帧间隔 P95 | 新实现帧间隔 P95 |
| --- | ---: | ---: | ---: | ---: |
| dot | 20 | 91 | 167ms | 17ms |
| compare | 19 | 91 | 183ms | 17ms |
| base | 16 | 91 | 367ms | 17ms |
| feature | 18 | 91 | 233ms | 17ms |

这不是手机真机帧率承诺，也不是重复采样的统计基准。3,000 个 DOM Marker 全部移除；特征/比较模式的 3,000 个预挂载 Vue 弹窗变为零。首次 GeoJSON/glyph 准备可能更慢（该次 base 从 305ms 增至 649ms），主要收益是连续移动时减少主线程 DOM 更新。Canvas/WebGL 与 DOM 文字抗锯齿仍有细微差别。

base 遮挡修复：MapLibre 先绘制所有图标、再绘制所有原生文字，导致底层文字透过上层背景。地名改为整张标签纹理，重复名称和字号复用缓存，仍沿用像素预算。桌面和竖屏浏览器像素回归验证：加入底层标签后，上层标签内部与单独显示时完全一致。3,000 个不同地名、DPR 3、Metal GPU 压测无错误，纹理总像素 16,965,396，最长边 107 像素，DOM Marker 为零；本次未做手机真机测量。
