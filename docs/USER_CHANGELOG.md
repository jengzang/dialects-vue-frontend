# 网站版本更新历史（用户版）

本文档整理网站从早期原生页面到当前版本的主要更新，面向普通用户说明“网站新增了什么、哪里更好用了、修复了哪些会影响使用的问题”。

整理口径：

- 以 `dev` 分支历史为准。
- `v4.2.0` 之后优先参考手写的首页更新公告，并结合提交历史补充细节。
- `v4.2.0` 之前根据历史提交与版本区间实际变化归纳。
- 早期未显式打版本号的用户可见节点，使用相邻正式版本下的整理版号细分，方便历史页展示连续演进。
- 只记录用户可感知的变化；内部维护事项只有在影响使用体验时才会改写后记录。
